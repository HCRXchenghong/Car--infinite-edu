# BCM（车身控制模块）

本目录为 BCM 预留，后续用于存放：

- BCM 硬件原理图、PCB 和器件资料；
- 车身电源、钥匙、灯光、制动、报警等控制逻辑；
- BCM 固件工程和驱动代码；
- BCM 与 VCU/上位机之间的 CAN FD 通信协议；
- BCM 的故障诊断、安全联锁和测试记录。

## 与 VCU 的边界

VCU 负责底盘运动解算与电机执行；BCM 负责车身级电源、输入和外围执行器管理。两者通过 CAN FD 交换状态与控制请求。

BCM 不应绕过 VCU 直接控制四轮转向或四轮驱动目标。涉及运动许可、急停、驱动器使能的信号，应同时经过约定的硬件安全链路和 CAN FD 状态交互。

具体 CAN ID、帧格式、心跳、故障码和信号定义待厂家协议及 BCM 设计确定后补充。
