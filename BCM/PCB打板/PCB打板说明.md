# BCM PCB 打板说明

> 文档状态：审查修订说明 v0.4（存在阻断项，未达到 Gerber 放行条件）
> 适用对象：四轮四转机器人底盘教育版 BCM 控制板
> 配套总体设计：[BCM 教育版总体设计](../总体设计.md)

逐页连接和纸质检验程序见 [HW-R1 硬件实施包](../../硬件设计包/00_使用说明与放行边界.md)。本文为制造准备说明，不是已放行生产工单。

## 1. 文档目的

本文用于指导 BCM 控制板从原理图、PCB 设计进入厂家打板和贴片阶段。本文只描述 PCB 实施、制造、装配和样板验收要求，不替代 BCM 总体设计中的功能定义。首版板框目标为 140 mm × 100 mm，连接器和继电器仍需按最终封装、安装孔和外壳关系完成机械确认。

BCM 与 VCU 是两个独立、并行推进的模块。BCM PCB 的供电、接口、调试和测试应能够独立完成，不应依赖 VCU PCB 才能进行上电检查、程序下载或基础功能验证。

## 2. 已确定的电气边界

### 2.1 电源边界

BCM PCB 只有一个外部电源输入：12V。车辆 48V 级电池到 12V 的大功率转换由外部 DCDC 完成；输入上下限按实际电池满充/截止/瞬态核验，不假定只有 48～54V。电池动力侧不进入 BCM PCB。BCM 的全部正式对外线束统一使用一个多针防水汽车母座 `J_BCM_EXT`；板载 12V 输入、继电器触点输出、电磁锁、推杆和低压信号通过同一壳体的不同针脚分组，不设置第二个车载母座。首版不从该母座引出未定义用途的 5V/3V3。

板内电源关系如下：

```text
外部 12V 输入
      │
      ├── K1～K8 继电器触点和 12V 负载
      ├── 电磁锁智能高边
      ├── MC33926 推杆 H 桥
      ├── 12V → 4.0V：EG800Z-GL
      ├── 12V → 5V：外设电源
      └── 5V → 3.3V：STM32、SHT31 和逻辑电路
```

板上不得使用电阻分压为 MCU、4G 模块或其他负载供电。12V→4.0V 电源应按 EG800Z-GL 的峰值电流和瞬态需求设计，当前总体方案要求能力不低于 3A。

### 2.2 负载与功率边界

| 区域/通道 | 数量 | 设计电流或能力 | PCB 实施重点 |
|---|---:|---:|---|
| BCM 总 12V 输入 | 1 | 15A 连续、20A 短时峰值目标 | 同一母座 +12V/GND 各使用 4 个并联针脚，按端子降额、温升和铜结构校核 |
| K1～K8 继电器触点输出 | 8 | 每路目标不超过 2A，暂定组合约 10～12A | 每路独立支路保护；触点公共电源和各路输出分区布线 |
| 电磁锁智能高边 | 1 | 5A 预留，实际约 1A | 功率器件散热、短路/过流保护和反馈隔离 |
| MC33926 推杆 H 桥 | 1 | 正常约 1A；堵转/启动待实测 | 5A 为器件峰值而非连续余量；完成结温、铜面积和故障恢复核算 |
| 4G 专用电源 | 1 | 4.0V、能力不低于 3A | 独立 DC/DC、近模块储能和电源完整性 |

外部 12V DCDC 不按 60A 或 70～80A 选型；首版以 15A 连续、20A 短时峰值为目标，但必须用实际负载表确认稳态、启动/堵转峰值、持续时间、占空比和最坏同时开启组合。K1 所含上位机、功放、显示、摄像头组和路由器尤其不得在没有实测的情况下假定总电流小于 2A。预算不闭合时必须调整硬件，不能只靠软件默认少开负载。

### 2.3 控制器和接口边界

| 功能 | 已确定方案 |
|---|---|
| MCU | STM32G491VET6，LQFP-100 |
| 主干通信 | CAN1，CAN FD |
| 扩展通信 | CAN2，预留 CAN 接口 |
| 温湿度 | 2 个 SHT31，共用 I2C，地址 0x44/0x45 |
| 4G | EG800Z-GL，UART DMA、环形缓冲区和非阻塞 AT 状态机 |
| 推杆 | MC33926 H 桥，两线电机，带故障输入和电流 ADC |
| 电磁锁 | 1 路独立智能高边，另有干节点状态反馈输入 |
| 继电器 | 8 路 12V 线圈，MOS 管低边驱动，线圈续流保护 |
| 下载升级 | SWD + CAN Bootloader |
| 唤醒 | 4G 唤醒、主干 CAN 唤醒、外部唤醒输入 |

### 2.4 车载接口实现约束

BCM 的所有正式对外车载线束接口统一使用一个带锁止、防水和防呆结构的多针汽车母座 `J_BCM_EXT`；不得使用 2.54mm 4 芯 UART 母头或普通排针替代。该母座中，+12V/GND、K1～K8 触点输出、电磁锁功率线和推杆电机输出占用经过电流校核的功率针脚，UART、CAN、唤醒和反馈信号占用其它针脚。首版 5V/3V3/4V0 均只在板内使用。

嘉立创商城候选为 `K776280WV-35-PTSNB`（C2997460）：4 mm 间距、三排 35P、直针、防水、PBT，页面标称额定电流 7A。页面列出的配套线束侧针座/胶壳/端子为 `K776231WV-1`、`K776164H-1`、`K770520T-1`。该器件只能作为封装评估候选；投板前必须取得厂家受控图纸，并通过样件确认焊盘、物理针号、压接线径、空腔堵头、锁止、工作温度、插拔/振动寿命和相邻针脚同时载流降额。商城库存不是生命周期保证。

35P 首版逻辑分组如下：

| 功能组 | 针脚数 | 说明 |
|---|---:|---|
| `+12V_IN` | 4 | 并联供电，15A 连续/20A 短时按每脚约 3.75A/5A 校核 |
| 输入 `GND` | 4 | 并联回流；汇流和回流路径按实际布局审查 |
| K1～K8 触点输出 | 8 | 每路不超过 2A，不与线圈驱动混用 |
| 电磁锁功率输出 | 2 | `LOCK_PWR_OUT/LOCK_GND`，独立高边保护回路 |
| 推杆电机 | 2 | MC33926 两线输出，单独走功率回路 |
| CAN1 | 3 | CANH/CANL/参考地 |
| CAN2 | 3 | CANH/CANL/参考地 |
| 外部 UART | 3 | TX/RX/参考地 |
| 唤醒 | 1 | 外部唤醒输入 |
| 急停 | 2 | 两线输入 |
| 锁反馈 | 2 | 干节点反馈，仅施加受限检测电流，不提供锁功率 |
| 备用 | 1 | 后续扩展或测试 |
| **合计** | **35** | 物理针号按最终封装图冻结 |

继电器线圈的 12V 供电和 MOS 低边驱动全部在 BCM 板内完成，不占用对外连接器针脚。继电器“通断线”指继电器触点输出线，不得在连接器定义中写成继电器线圈供电。急停输入不得串入或加载 VCU 主硬件急停回路，应使用独立辅助触点或经过隔离的安全状态。

SWD、串口日志和生产测试仅通过壳体内测试焊盘、测试夹具或临时维护接口访问。4G 天线可使用板内 U.FL/IPEX 到密封射频穿墙件的专用同轴连接，该通道不属于多针车载母座。

## 3. 打板前必须准备的文件

### 3.1 设计文件

进入生产前应至少形成以下文件，并确保版本号一致：

1. 原理图源文件和 PDF；
2. PCB 源文件、板框和机械层；
3. 元件封装库及关键器件 3D 模型；
4. BOM，区分贴片、插件、手焊和不装件；
5. Gerber 或厂家要求的生产图层；
6. NC Drill 钻孔文件，包含 PTH 和 NPTH；
7. 坐标文件（Pick and Place/XY）；
8. 钢网文件；
9. 装配图，包含正反面位号和极性；
10. 关键网络、阻抗、铜厚、表面处理和外形尺寸说明；
11. 首件测试和上电检查记录表。

### 3.2 版本和文件命名

BCM 和 VCU 使用相同的目录和文件命名规则，模块内容分别维护。建议本目录后续采用以下命名：

```text
BCM_PCB_<版本>_SCH.pdf
BCM_PCB_<版本>_GERBER.zip
BCM_PCB_<版本>_DRILL.zip
BCM_PCB_<版本>_BOM.xlsx
BCM_PCB_<版本>_CPL.csv
BCM_PCB_<版本>_ASM.pdf
BCM_PCB_<版本>_TEST.md
```

版本号应同时写入 PCB 丝印、原理图标题栏、BOM、Gerber 压缩包和装配图。若仅修改丝印或不影响电气的机械信息，也要在发布记录中注明。

## 4. 原理图分区要求

PCB 设计前，原理图应按功能分区并使用统一网络命名。建议至少拆分为以下页面或层级：

### 4.1 输入和电源保护

- `J_BCM_EXT` 多针防水汽车母座及正负极、针脚 1 标识；
- 输入 TVS、反接保护和输入滤波；
- 靠近源端的主保护，以及 K1～K8、电磁锁、推杆和板载电源的独立支路保护；
- 12V 主电源分配点；
- 12V→5V DC/DC；
- 12V→4.0V 4G 专用 DC/DC；
- 5V→3.3V Buck，或经最坏温升证明可接受的其它稳压方案；
- 3.3V 监控和复位芯片；
- 关键电源测试点和电流测量预留点。

保护器件的工作电压、钳位电压、脉冲能力和封装散热必须结合外部 DCDC 参数核对，不能只按名义 12V 选型。

### 4.2 继电器输出

8 路通道统一编号为 K1～K8，并在原理图、PCB 丝印、线束表和软件逻辑通道中保持一致：

```text
K1：上位机、功放、显示板、摄像头组、路由器
K2：风扇
K3：前灯一体
K4：后灯一体
K5：左转向灯
K6：右转向灯
K7：自动驾驶灯
K8：巡逻灯
```

每路继电器线圈由 STM32 GPIO 经 MOS 管低边驱动。线圈两端设置续流保护，GPIO 侧设置默认关闭状态，确保 MCU 复位、下载和掉电过程中继电器不误吸合。

K2～K8 暂不设置继电器触点反馈。K1 至少增加触点后输出电压检测，或改用带诊断的电源开关，以闭合远程唤醒结果。K1～K8 必须设置板载保险/eFuse/PTC，或在线束靠近源端设置具有明确额定值和位号的独立支路保险；15A/20A 主保护不能保护 2A 支路线束。不要在 PCB 或软件说明中把线圈驱动状态描述成触点实际吸合状态。

继电器必须按具体 12V DC 负载的容性浪涌、感性反冲、分断能力和寿命降额；负载侧 TVS、续流或浪涌抑制应进入原理图和线束设计。

### 4.3 电磁锁和推杆

电磁锁功率通道和 K1～K8 继电器区分开：

- 智能高边器件靠近电磁锁电源输出端；
- 功率地回路直接回到功率地汇流点；
- 过流/短路诊断信号回 MCU；
- 两根干节点反馈线使用独立输入通道；
- 反馈输入施加受限检测电流，按触点润湿要求核算，不能提供锁功率；
- 反馈电路采用隔离或限流、上拉后的数字输入方式，并预留有效电平配置空间。

MC33926 区域应包含：

- 推杆两线电机输出并入 `J_BCM_EXT`，不再设置第二个 BCM 车载母座；
- 逻辑控制输入；
- 故障输入；
- 电流反馈 ADC；
- 电机电源和功率地去耦；
- 便于示波器探头接入的测试点。

必须从实际推杆规格确认内置 OPEN/CLOSE 终点开关或位置反馈。电流/超时仅作为后备保护；若需要外置双限位，原理图应增加 `ACT_OPEN_LIMIT/ACT_CLOSE_LIMIT`，并在 35P 针脚不足时重新选择/拆分连接器，不能占用一个备用针后遗漏另一方向。

打板前必须实测推杆正常、启动和堵转电流。若堵转接近 MC33926 的 5A 峰值能力，应改用具有明确连续电流、峰值和热余量的 H 桥。首件测试同时验证过流调节、短路锁存、过温、故障清除和反向死区。

MC33926 的故障输出按开漏有效低设计上拉；`EN/D1/D2/IN1/IN2` 使用外部确定性偏置，保证 MCU 高阻或复位时输出关闭。FB 是比例电流输出，取样电阻、ADC 量程、RC 滤波和钳位按数据手册及最大电流计算。

推杆只能执行 OPEN、CLOSE、STOP。PCB 不负责自动反向，但应保证软件或安全逻辑能够在反向前先关闭原方向并经过死区。

### 4.4 MCU、通信和传感器

STM32G491 区域应集中放置：

- MCU 最小系统、NRST、BOOT 和 SWD；
- 两路 FDCAN 收发器接口；
- I2C 及两个 SHT31 地址配置；
- EG800Z-GL UART；
- 外部唤醒、急停、锁反馈、MC33926 故障和 ADC；
- 独立硬件看门狗/监督器；
- 状态 LED 和维护按键。

CAN 收发器、4G 模块、电源开关节点和继电器功率区不要直接围绕 MCU 高频敏感引脚布置。所有进入 MCU 的外部信号应在接插件或板边附近完成必要的限流、滤波和 ESD 保护。

## 5. PCB 层叠和电流承载

### 5.1 层叠建议

BCM 同时包含 15A 连续、20A 短时峰值的 12V 功率回路和 MCU、CAN、4G 等逻辑/射频电路，推荐优先评估 4 层板：

| 层 | 建议用途 |
|---|---|
| L1 | 器件、关键短线、低压控制和局部功率铜 |
| L2 | 连续 GND 平面，必要处为功率地规划回流 |
| L3 | 12V、5V、4.0V、3.3V 电源平面或大面积电源铜 |
| L4 | 低速信号、维护信号和补充功率铜 |

最终层叠、介质厚度、铜厚、阻焊开窗和表面处理以板厂能力和热设计核算为准。若选用 2 层板，必须重新校核高电流压降、温升、回流路径和逻辑地完整性，不能仅通过加宽普通走线替代功率结构。

### 5.2 主电源和 K1 回路

12V 输入到 K1 公共端、K1 触点输出和回到输入负端的路径是整板最重要的功率网络：

- 主电流尽量从连接器直达功率分配区，避免穿过 MCU、4G 和传感器区；
- 12V 输入和 K1～K8 触点公共电源使用 `J_BCM_EXT` 的大电流针脚、加宽铜箔或必要的铜结构；
- 正负极都要有连续、短而低阻的路径，不能只加宽正极而忽略回流；
- 走线拐角使用圆弧或 45°，避免狭窄颈部和孤立热焊盘；
- 必要时通过多层并联过孔、铜柱、压接端子或额外铜条降低阻抗；
- 线宽和铜厚必须由目标温升、长度、允许压降和板厂能力反推，不使用经验值直接放行。

K2～K8 虽然单路设计电流较低，但公共 12V 分配区域可能承受多路叠加电流，应按最坏组合工况设计。

### 5.3 低压电源和地

- 4.0V 4G 电源单独从 12V 输入功率区取电，不能从 5V 或 3.3V 级联产生；
- EG800Z-GL 供电入口就近放置大容量和高频去耦，具体容量按模块数据手册和实测发射峰值确认；
- 3.3V 逻辑电源远离继电器线圈和 MC33926 开关节点；
- 模拟电流反馈 ADC 使用干净回路和必要的 RC 滤波；
- 功率地、数字地和模拟采样回流应有明确汇流关系，避免大电流回流穿过 MCU 地脚和 ADC 地脚；
- DC/DC 开关节点面积尽量小，反馈分压远离电感、二极管和功率开关节点。

### 5.4 板框与机械可行性

BCM 首版板框目标为 **140 mm × 100 mm**。在支路保护、真实继电器/连接器封装、安装孔和外壳 3D 模型导入前，不得作出“可行且余量合理”的冻结结论：

- 优先使用紧凑型板载继电器；即使选用体积较大的插件继电器，也必须按实际封装核对，不得默认继电器插拔空间可省略；
- 35P 母座应沿板边布置，插拔方向不能与继电器、4G 模块或外壳筋位冲突；
- 继电器优先沿长边分两排或紧凑阵列布置，输入保护和功率汇流区靠近母座，板框为功率走线和散热保留余量；
- 4G 模块、SIM、4.0V DC/DC 与天线区必须保留射频禁布和维护空间；
- 采用 4 层板、外层 2 oz 铜的方案更稳妥，主电源和继电器公共回路必须用铜皮/多过孔结构；
- 最终放行前必须导入实际封装做 3D 干涉、插拔空间、安装孔和散热核对。

若最终继电器、4G 模块或外壳结构仍发生干涉，应优先调整器件布局或局部机械结构；只有实际 3D 核对无法满足插拔、散热和安装要求时，才重新扩大板框。

## 6. 器件布局要求

建议按“输入/大电流区—负载驱动区—电源转换区—数字控制区—通信/4G 区”进行分区。

### 6.1 输入和继电器区

输入连接器、主保护器件、K1～K8 继电器及负载连接器优先靠近板边，方便线束插拔和电流路径控制。K1 不应被放在细线绕行的位置，也不应让 K1 主回路穿过 MCU 下方。

继电器之间保留足够的装配、焊接和返修空间。若使用插件继电器，焊盘、孔径、环宽和焊接面按厂家封装核对，并为大电流引脚设置足够的铜面积。

### 6.2 功率器件区

智能高边和 MC33926 靠近各自输出连接器，缩短功率回路。功率器件底部和周边预留散热铜、导热过孔或机械散热接口；散热铜不能破坏安全间距和相邻信号布线。

### 6.3 MCU 和低速外设区

MCU、晶振/时钟、复位、看门狗和调试接口集中放置。SHT31 的 I2C 线尽量短，远离继电器线圈、4G 天线/射频区域和 DC/DC 开关节点。

### 6.4 4G 区

EG800Z-GL、板载 SIM 卡座/卡槽、`RF_UFL_4G` 天线同轴连接、4.0V DC/DC 和去耦器件集中规划。若使用外置天线，射频接口靠近板边，射频走线遵循模块和天线厂商的阻抗、禁布区和地参考要求。4G 区不应被大电流铜排、继电器线圈和高噪声开关节点包围。

## 7. 布线和信号完整性

### 7.1 CAN FD

CAN1 为主干 CAN FD，CAN2 为预留 CAN。每一路应具备：

- CANH/CANL 差分走线；
- 接插件附近的 ESD/浪涌保护；
- 共模电感预留位；
- 120Ω 终端电阻配置位；
- 收发器待机/使能控制；
- 端口名称和网络方向清晰丝印。

终端电阻应通过跳帽、拨码或可替换配置实现，首版不要把是否终端直接永久焊死。CANH/CANL 走线保持相邻、短、连续，避免与继电器触点和 MC33926 电机回路平行长距离布线。

### 7.2 I2C、UART 和唤醒输入

- SHT31 两个地址必须在原理图、丝印和软件配置中对应；
- 舱内 SHT31 远离 4G、DC/DC 和继电器热源；若使用远置传感器，不直接采用长线裸 I2C；
- I2C 上拉电阻靠近总线主控侧，阻值根据总线电容和速率确认；
- EG800Z-GL UART 采用 UART DMA 所需的稳定电平和清晰复位/唤醒信号；该 UART 仅在板内连接，不设计为对外 4 芯母头；
- 外部唤醒输入设置限流、滤波和过压保护；
- CAN 唤醒按实际收发器验证常电域、唤醒输出路径、待机电流和误唤醒；HW-R1 的 TCAN1044AV-Q1 通过 RXD 指示，无独立 WK/INH；
- 急停输入、锁反馈和 MC33926 故障输入不要与普通可配置 GPIO 混淆，网络名需体现安全/故障属性。

### 7.3 继电器和电机噪声

线圈续流器件靠近线圈驱动回路，MOS 管栅极串联限流并设置默认关闭。MC33926 的逻辑地和功率地回路按器件手册布置，电流采样线避开电机输出和开关节点。

## 8. 丝印、连接器和可维护性

所有正式对外车载接口均使用防水汽车连接器，并有方向、针脚 1、电源极性、信号名称和额定用途标识。建议统一使用以下逻辑命名，实际连接器编号以原理图为准：

```text
J_BCM_EXT       BCM 全部对外接口；一个多针防水汽车母座
                功率组：+12V_IN、输入 GND、K1～K8 触点输出、锁功率线、推杆电机两线
                小电流组：CAN1、CAN2、UART 及各自参考地、唤醒、急停、锁反馈
                5V、3V3、4V0 首版均仅板内使用
RF_UFL_4G       4G 天线板内同轴接口，连接密封射频穿墙件
TP_SWD          SWD、NRST、BOOT 和地测试焊盘；不作为对外线束接口
```

丝印至少应标出 `+12V`、`GND`、`CANH`、`CANL`、`3V3`、接口编号、K1～K8 通道名称和推杆电机正/反向定义。高电流接口附近标注“断电后再插拔”或同等维护提示；相同外形的低压连接器必须用机械防呆、颜色或明确丝印避免误插。

## 9. 制造和装配要求

### 9.1 PCB 制造询价参数

发给板厂的询价包应明确：

- 板材体系和层数；
- 内外层铜厚，尤其是主电源层；
- 板厚及允许公差；
- 表面处理；
- 最小线宽/线距、最小孔径和阻焊能力；
- 阻抗要求（如有）；
- 板框、V-CUT/邮票孔、工艺边和定位孔；
- 是否需要沉孔、金手指、压接铜件或铜排；
- 是否包含贴片、插件、手焊和清洗；
- 是否要求三防涂层及禁涂区域。

### 9.2 BOM 和可制造性

- K1～K8 继电器的线圈电压、触点额定值、封装和插拔方向必须与 PCB 封装一致；
- 防水汽车连接器应核对端子压接范围、线径、额定电流、锁止、防呆、空腔堵头和与外壳/线束的防水能力；
- 4G DC/DC、MC33926、智能高边和 TVS 的热焊盘/散热焊盘应给出钢网开口建议；
- 极性器件、二极管、TVS、电解电容、连接器和模块必须在装配图中有明确方向；
- 对缺货或替代料提前定义可替代范围，不能在贴片后临时更改关键电源和安全器件。

### 9.3 三防和外壳

总体方案建议 BCM PCB 做三防涂层，但裸 PCB 不等同于防泼溅结构。三防涂层前应遮蔽连接器触点、继电器插接面、SWD、按键、天线连接器和需要散热/接触的区域。最终防护能力还取决于外壳、密封件、线束出线和连接器。

## 10. 首件上电和功能测试

### 10.1 装配后目检

1. 检查板框、孔位、连接器方向和继电器插拔空间；
2. 检查主电源正负极、TVS、反接保护和大电流铜结构；
3. 检查 MCU、SHT31、4G 模块、MC33926、收发器和监督器的极性/方向；
4. 检查所有未装件、跳帽、终端电阻和配置电阻；
5. 检查焊桥、虚焊、少件、偏件和残留助焊剂；
6. 对 12V、5V、4.0V、3.3V、GND 做短路和阻值检查。

### 10.2 分级上电

使用限流电源分级上电，顺序建议为：

```text
不装负载 → 12V 限流上电 → 检查 5V/4.0V/3.3V
        → SWD 下载和复位 → CAN 收发器检查
        → 4G 空载/通信测试 → 继电器线圈测试
        → 锁高边和推杆假负载测试 → 最后接入真实负载
```

4G 模块首次上电重点观察 4.0V 电源跌落、启动电流和串口状态。继电器测试先使用指示灯或电子负载，确认 GPIO 默认态、线圈驱动和续流保护后再接入 K1 等真实负载。

### 10.3 必测项目

| 类别 | 验收内容 |
|---|---|
| 电源 | 12V 输入极性保护、5V/4.0V/3.3V 电压、纹波、启动和掉电行为 |
| MCU | SWD 下载、复位、BOOT、时钟、看门狗复位 |
| CAN | CAN1/CAN2 收发、终端配置、错误计数和总线掉线行为 |
| 继电器 | K1～K8 单路/组合动作、默认断开、线圈电流和温升 |
| 支路保护 | K1～K8、锁、推杆及板载电源短路/过流动作；故障不造成线束或连接器过热 |
| 电磁锁 | 高边开关、过流/短路关闭、干节点反馈和有效电平配置 |
| 推杆 | OPEN/CLOSE/STOP、故障输入、电流 ADC、超时/堵转停止 |
| 推杆终点 | 内置或外置 OPEN/CLOSE 限位、断线行为和限位触发停止 |
| 传感器 | 两个 SHT31 地址、CRC、掉线和风扇故障默认开启 |
| 4G | UART DMA、AT 超时重试、唤醒、模块复位和峰值供电 |
| 休眠 | K1～K8、锁、推杆输出关闭以及 4G/外部/CAN 唤醒 |
| 低功耗 | STANDBY/SLEEP 各电源域、静态电流、4G 弱信号重连功耗、唤醒延时和停放续航 |

## 12. 仍待冻结的事项

以下内容不影响本文作为准备清单使用，但都属于 Gerber 发布前必须关闭的阻断项：

1. 140 mm × 100 mm 板框内的安装孔、定位基准、连接器朝向和外壳关系；
2. 具体继电器、`J_BCM_EXT` 35P 候选件的最终封装/物理针号/端子规格、DC/DC、智能高边和 TVS 型号；
3. 覆盖实际电池全电压范围的外部 12V DCDC 最终型号和接口；
4. 各继电器、锁、推杆和灯光的线束规格；
5. 电磁锁干节点最终为常开还是常闭；
6. CAN 速率、CAN FD 数据段配置、终端位置和通信协议；
7. 三防涂层、灌封或外壳的最终工艺；
8. 量产测试夹具、测试点位置和测试软件。
9. MCU Pinmap、CAN 低功耗唤醒电路和自研 CAN Bootloader 的分区/回滚设计；
10. K1～K8、锁、推杆、4G 和板载电源的完整功率预算及支路保护额定值。
11. 推杆内置终点开关/位置反馈；若需外置双限位，其连接器针脚和断线安全行为。

## 13. 交付判断

当所有“打板放行检查表”项目完成、待冻结项中影响安全和制造的内容已关闭，并且板厂确认大电流铜结构、连接器和插件工艺可制造后，BCM PCB 才可进入首版打板。首版样板应优先验证电源、继电器、4G 供电、推杆和接口保护，再接入整车负载。
