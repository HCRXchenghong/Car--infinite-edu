# BCM 教育版总体设计

**文档状态：审查修订稿（未达到原理图冻结条件）**  
**版本：V1.3**  
**日期：2026-09-19**

硬件实施细节、完整建议 Pinmap 和检验程序以 [HW-R1 硬件实施包](../硬件设计包/00_使用说明与放行边界.md) 为当前设计输入；仍需关闭其中 H 项，本文不是可直接投板的图纸。

## 1. 设计目标

本 BCM 用于教育版四轮四转机器人底盘，负责车身灯光、上位机电源域、风扇、推杆、电磁锁、温湿度监测、4G 唤醒和 CAN 通信。

本版本采用 STM32 主控和继电器输出方案，取消原设计中的 20 路智能高边灯光输出，保留一条电磁锁智能高边通道和一套 MC33926 推杆 H 桥。

机械臂控制器不由 BCM 直接控制，仅预留 CAN 接口。

## 2. 当前总体方案

### 2.1 主控

| 项目 | 当前方案 |
|---|---|
| MCU | STM32G491VET6 |
| 封装 | LQFP-100 |
| 主频 | 最高 170 MHz |
| Flash | 512 KB |
| 主要资源 | 双 FDCAN、ADC、SPI、I2C、UART、DMA、定时器 |
| 下载升级 | SWD + CAN Bootloader |

### 2.2 电源架构

BCM 只有一个外部电源输入：**12V**。

车辆 48V 级电池到 12V 的大功率转换由外部 DCDC 完成；实际满充/截止和瞬态范围按电池、BMS 核验，不能假定全部只在 48～54V。BCM 板上只完成低压电源转换和负载控制。

```text
48V 级电池（实际范围待核验）
      │
      ▼
外部大功率 DCDC
      │ 12V
      ▼
BCM 单路 12V 输入
      ├── K1～K8 继电器触点及 12V 负载
      ├── 电磁锁智能高边
      ├── MC33926 推杆 H 桥
      ├── 12V → 4.0V：EG800Z-GL
      ├── 12V → 5V：外设电源
      └── 5V → 3.3V：STM32、SHT31、逻辑电路
```

板载降压必须使用 DC/DC 或稳压模块，不能使用电阻分压为 MCU、4G 或其他负载供电。

外部 12V DCDC 不按 60A 或 70～80A 选型。BCM 的 12V 输入首版以 **15A 连续、20A 短时峰值**作为设计目标，而不是已经验证的结论。原理图冻结前必须建立逐负载功率预算，至少记录 K1～K8、电磁锁、推杆、4G、继电器线圈和板载电源的稳态电流、启动/堵转峰值、持续时间、占空比和最坏同时开启组合。连续工况还必须保留设计余量；预算不闭合时应扩大电源/连接器/铜结构能力或减少、拆分负载，不能用软件默认少开几路作为硬件保护。

5V→3.3V 在接近 1A 时优先使用 Buck。若使用线性稳压器，必须提交最坏输入、电流、环境温度和铜面积条件下的功耗及结温证明。

### 2.3 继电器数量

共使用 8 路 12V 继电器：

| 继电器 | 控制对象 | 设计电流 |
|---|---|---:|
| K1 | 上位机、功放、显示板、摄像头组、路由器 | ≤2A |
| K2 | 风扇 | ≤2A |
| K3 | 前灯一体 | ≤2A |
| K4 | 后灯一体 | ≤2A |
| K5 | 左转向灯 | ≤2A |
| K6 | 右转向灯 | ≤2A |
| K7 | 自动驾驶灯 | ≤2A |
| K8 | 巡逻灯 | ≤2A |

继电器统一采用 12V 线圈。每路触点按不超过 2A 的实际负载设计；继电器线圈由 BCM 板内 12V 供电并由 STM32 经 MOS 管低边驱动。触点通断输出线从统一车载母座引出，不能把触点输出线误当成线圈供电线。

所有继电器线圈由 STM32 通过 MOS 管低边驱动，并在线圈两端增加续流保护。

K2～K8 暂不设置继电器触点反馈。K1 负责上位机电源域和远程唤醒，至少应增加触点后输出电压检测，或改用带诊断的电源开关，以便判断上电成功、超时和粘连/断路故障。K1～K8 每一路触点输出必须设置与支路线径、连接器、负载浪涌和继电器 DC 分断能力匹配的独立保护，可采用板载保险、eFuse/PTC，或在线束靠近电源源端设置有明确位号和额定值的支路保险。15A/20A 主保护不能替代 2A 支路线束保护。电磁锁、推杆和板载电源同样必须有可验证的短路/过流保护路径。

继电器选型不能只比较“2A”标称值；必须按 12V DC 负载的容性启动浪涌、感性反冲、触点材料、分断能力和目标寿命降额，并在负载端配置适当的 TVS、续流或浪涌抑制。

## 3. 功率预算

| 功能 | 最大设计电流 |
|---|---:|
| K1～K8 继电器触点输出 | 约 10～12A 暂定负载组合；每路目标不超过 2A，待实测 |
| 电磁锁智能高边 | 5A 预留，实际约 1A |
| 推杆 MC33926 | 正常约 1A；堵转/启动待实测，不能把器件 5A 峰值能力当连续余量 |
| 板载 DC/DC、MCU、4G 和继电器线圈 | 必须按实际器件、效率和启动峰值核算 |
| BCM 12V 输入设计目标 | 15A 连续、20A 短时峰值；预算闭合后方可冻结 |

继电器触点公共电源与板载 DC/DC 共用 BCM 的 12V 输入电源域，但触点输出线和线圈驱动线必须在原理图、连接器针脚和 PCB 区域上明确区分。12V 输入正负极、继电器触点公共电源分配和各路触点输出按 15A 连续、20A 短时峰值校核；不能再按 65～70A 设计，也不能让继电器线圈电源占用触点输出针脚。若实测负载组合超过 12A 连续或 20A 短时峰值，必须重新核算外部 DCDC、连接器和铜结构，不能靠软件“默认少开几路”来掩盖电源不足。

## 4. 负载和控制逻辑

### 4.1 K1 上位机电源域

K1 同时给以下设备供电：

- 上位机
- 功放
- 显示板
- 摄像头组
- 路由器

K1 暂定设计电流不超过 2A，但该数值必须由上位机、功放、显示板、摄像头组和路由器的实测稳态电流及启动浪涌共同确认。若总电流或浪涌超过 2A，必须拆分电源域，或同步升级继电器、支路保护、端子、线径和 PCB 铜结构；不能只修改软件限流。K1 的线圈供电由 BCM 板内 12V 提供，K1 触点的通断输出通过统一车载母座引出。

EG800Z-GL 不由 K1 控制，使用 BCM 常电待机电源单独供电，以支持远程唤醒。

### 4.2 风扇

风扇由 K2 控制。

- 正常情况下由温度、湿度阈值控制
- 阈值可由上位机设置
- 必须设置开启和关闭回差
- 支持 CAN 强制开启
- 任一关键温湿度传感器掉线时，风扇默认开启
- K2 不做触点反馈

推荐控制优先级：

```text
急停输出策略（见第 7 章）
        > 传感器故障强制开启
        > CAN 强制开启
        > 温湿度自动控制
```

### 4.3 灯光

灯光全部采用继电器通断控制，不由 STM32 生成闪烁波形。

- 前灯和后灯允许同时开启
- 左转和右转允许同时开启，实现双闪
- 转向灯为通电自闪型
- 自动驾驶灯在自动驾驶模式下自动开启
- 巡逻灯由上位机控制
- 不实现灯光闪烁算法
- 不保留三色模式指示灯
- 上装灯取消

### 4.4 电磁锁

电磁锁采用 1 路独立智能高边开关：

- 实际工作电流约 1A
- 按 5A 能力预留
- 通电上锁
- 断电开锁
- 继电器急停策略不适用于电磁锁，电磁锁由独立智能高边控制
- 过流、短路或急停时立即关闭

电磁锁为四根线：

```text
两根：锁电源线
两根：干节点锁状态反馈线
```

反馈输入不向反馈线提供锁功率，但须施加受限的检测电流（例如上拉/隔离输入），按触点最小润湿电流核算。“干节点”不是完全不加检测电压。默认按“上锁完成后干节点闭合”处理，实际接点定义仍需核验，并保留有效电平配置和消抖。

### 4.5 上盖推杆

推杆使用 MC33926 H 桥控制，电机只有两根线，通过交换正负极改变方向。

```text
OPEN   ：正向运行
CLOSE  ：反向运行
STOP   ：停止
```

推杆正常电流暂估约 1A，堵转电流必须用实际执行器、行程、负载和 12V 电源实测。MC33926 的 5A 是峰值能力，连续能力取决于封装散热；若实测堵转接近 5A，应选用更高电流余量的 H 桥，不能把“峰值等于堵转”作为可靠设计。

“不自动反向”的含义：

- 开启过程中不会自动切换为关闭
- 关闭过程中不会自动切换为开启
- 过流、堵转或超时后只停止，不自动反向
- 收到新的反向命令时，先停止，再经过短暂死区，最后允许改变方向

推杆保留 MC33926 电流反馈 ADC，用于过流、堵转和动作超时判断。

必须确认实际推杆是否带内置 OPEN/CLOSE 终点开关或位置反馈。优先选择带可靠内置限位、且堵转/断电行为有数据手册说明的执行器；电流和超时只作为后备保护，不作为唯一终点判据。若需要外置双限位，必须为 `ACT_OPEN_LIMIT/ACT_CLOSE_LIMIT` 重新分配连接器针脚并让限位直接参与停止逻辑；当前 35P 仅有 1 个备用针，不能在不调整接口的情况下容纳两路外部限位。

MC33926 的故障输出为开漏有效低信号，需要明确上拉和上电默认态；`EN/D1/D2/IN1/IN2` 必须用外部上拉/下拉保证 MCU 复位、下载和掉电时 H 桥关闭。FB 为比例电流输出，应按数据手册选择取样电阻并加入 ADC 限幅/滤波，不能把 FB 直接当电压源接入 ADC。

### 4.6 机械臂

机械臂不由 BCM 直接控制，不占用继电器和高边输出资源，仅预留 CAN 接口供后续扩展。

## 5. 通信和接口

### 5.1 主干 CAN 和预留 CAN

STM32G491 的两路 FDCAN 分配如下：

| 接口 | 用途 |
|---|---|
| CAN1 | 主干 CAN FD |
| CAN2 | 预留 CAN，后续可接机械臂等设备 |

CAN 报文 ID、信号定义、周期、超时时间、CRC 和 Alive Counter 暂不冻结，后续根据整车通信协议确定。软件先提供统一 CAN 驱动、报文队列、信号打包和解包接口。

主干 CAN 唤醒需要明确常电域、待机电流、实际唤醒输出、MCU 低功耗模式和误唤醒过滤。HW-R1 候选 TCAN1044AV-Q1 通过 RXD 指示唤醒，没有独立 WK/INH；VCC/VIO 和 MCU 对应唤醒能力必须保留。下载升级中的 CAN Bootloader 按自研应用 Bootloader 设计，不假定芯片系统 Bootloader 自动满足需求；必须定义镜像完整性、版本检查、断电恢复、回滚和升级权限。

### 5.2 4G 模块

模块：EG800Z-GL。

软件采用：

- UART DMA 接收
- 环形缓冲区
- 非阻塞 AT 命令状态机
- AT 命令队列
- 响应匹配和超时重试
- 远程唤醒
- 状态通信

本版本暂不实现 4G OTA。

任何来自 4G 的远程唤醒、参数或控制请求都必须具备设备身份校验、加密传输、序号/时间窗或等效重放保护、权限控制和安全的凭据存储。网络异常、认证失败或重复报文不得直接改变车身输出；运动控制仍只能由 VCU 按控制权规则执行。

### 5.3 温湿度传感器

两个 SHT31 共用一路 I2C：

| 地址 | 用途 |
|---|---|
| 0x44 | 舱内温湿度 |
| 0x45 | 控制板区域温湿度 |

驱动需要包含 CRC 校验、掉线检测、合理范围检查、数据滤波和传感器状态管理。

舱内温湿度传感器不能紧邻 4G、DC/DC、继电器或其它发热器件，否则会产生系统性温度偏差。若舱内传感器离板较远，应使用短线传感器子板或抗干扰转换方案，不把裸 I2C 直接铺成长车载线束。

### 5.4 唤醒输入

支持三类唤醒来源：

- EG800Z-GL 4G 唤醒
- 主干 CAN 唤醒
- 外部唤醒输入

外部唤醒输入采用带限流、滤波和过压保护的数字输入电路。

### 5.5 其他输入

保留以下输入功能：

- 急停状态输入
- 电磁锁干节点反馈输入
- 推杆 MC33926 故障输入
- 推杆电流 ADC 输入

### 5.6 车载线束接口统一要求

BCM 所有正式对外车载线束统一使用一个带锁止、防水、防呆的多针汽车母座，逻辑编号为 `J_BCM_EXT`。不再设置第二个 BCM 车载母座。

`J_BCM_EXT` 在同一个壳体内按功能分组分针脚：

- 大电流/功率针脚：BCM 板载 `+12V_IN`、输入 `GND`，K1～K8 继电器触点输出、`LOCK_PWR_OUT/LOCK_GND` 和两根推杆电机输出；`+12V_IN` 与输入 `GND` 首版各使用 4 个并联针脚，禁止用单个 7A 标称针脚承载整板输入；
- 首版不对外引出未定义用途的 `5V`、`3V3` 或 4G 专用 `4V0`，避免短路、反灌和回流不清；以后若确需增加，必须重新分配连接器并加入独立限流、短路保护和回流针脚；
- 小电流信号针脚：CAN1、CAN2、外部 UART、唤醒、急停和锁反馈；CAN1、CAN2、UART 各保留专用参考地。推杆控制、故障和电流采样保持板内连接，不占用车载母座针脚；
- 继电器线圈供电和线圈驱动不作为对外接口，全部由 BCM 板内完成；
- 触点输出线、电磁锁/推杆功率线和信号线必须使用不同针脚并在原理图、丝印、线束表中清楚标识，不能因为共用一个母座而在电气上混接。

嘉立创商城已查到候选：[K776280WV-35-PTSNB（C2997460）](https://item.szlcsc.com/3468812.html)，4 mm 间距、三排 35P、直针、防水、PBT，页面标称额定电流 7A。配套资料列出的线束侧针座为 `K776231WV-1`、胶壳为 `K776164H-1`、端子为 `K770520T-1`。该型号只能作为评估候选；正式投板前必须取得厂家受控图纸，核对焊盘、端子、胶壳、防水塞、线径、工作温度、寿命和相邻针脚降额，并完成样件温升/插拔/振动验证。“7A/触点”不能直接等同于整座连接器可承载所有针脚同时满载，商城库存也不能作为生命周期和供货保证。

35P 的首版逻辑分配为：`+12V_IN` 4 针、输入 `GND` 4 针、K1～K8 8 针、电磁锁功率输出 2 针、推杆电机 2 针、CAN1 3 针（H/L/参考地）、CAN2 3 针（H/L/参考地）、外部 UART 3 针（TX/RX/参考地）、唤醒 1 针、急停 2 针、锁反馈 2 针、备用 1 针，共 35 针。最终物理针号、相邻针分组和屏蔽/地策略按厂家图纸、线束拓扑和温升/EMC 样件测试冻结。

BCM 急停输入必须来自 VCU 安全状态或急停按钮的独立辅助触点，不得串入、加载或削弱 VCU 的主硬件急停回路。

EG800Z-GL 与 MCU 的板内 UART 仍保持板内连接；若有其它 UART 需要对外引出，统一使用 `J_BCM_EXT` 的小电流针脚。SWD、串口日志和生产测试仅保留为密封外壳内的测试焊盘或测试夹具。若舱内 SHT31 不安装在 BCM 板上，不能把裸 I2C 作为长距离车载线束直接引出；应采用短线本地传感器子板或经评估的抗干扰转换方案。

4G 天线如需出壳，板内可使用 U.FL/IPEX 等专用 50Ω 射频连接，外壳处使用密封射频穿墙件；该射频通道不替代也不使用多芯车载线束连接器。

## 6. 状态机

BCM 主状态建议如下：

```text
INIT → SELF_CHECK → STANDBY
                    │
                    ├── 唤醒事件 → WAKE_REQUEST → SELF_CHECK → POWER_ON → NORMAL_RUN
                    │                                            │             ├── DEGRADED_RUN
                    │                                            │             └── FAULT
                    └── 休眠条件 → SLEEP
```

STANDBY 和 SLEEP 都可由 4G、主干 CAN 或外部唤醒输入触发并进入 `WAKE_REQUEST`，随后执行自检；这样与待机/休眠阶段保留的唤醒能力保持一致。

必须分别冻结 STANDBY 和 SLEEP 的常电电源域、模块实际支持的低功耗模式、目标静态电流、允许唤醒延时和停放续航。EG800Z-GL 的 PSM/eDRX 支持与下行可达性未经本次资料核验，不得默认具备。4G 弱信号/反复重连时的平均与峰值电流必须实测，不能只以实验室强信号待机电流估算续航。

### 6.1 待机

待机状态只保持必要的 MCU、监控电路和 EG800Z-GL 电源。K1～K8 默认断开，电磁锁和推杆默认关闭。

### 6.2 唤醒

4G、主干 CAN 或外部唤醒输入产生有效事件后，BCM 唤醒并执行自检。自检完成后，根据上位机和整车状态控制 K1～K8。

### 6.3 运行

运行状态中执行继电器控制、灯光逻辑、风扇控制、推杆控制、电磁锁控制、CAN 通信和 4G 状态通信。

### 6.4 休眠

满足休眠条件时：

- K1～K8 断开
- 电磁锁高边关闭
- 推杆停止
- 保留 MCU 低功耗唤醒能力
- 保留 EG800Z-GL 远程唤醒能力

## 7. 故障策略

按教育版默认故障策略执行：

| 故障 | 处理 |
|---|---|
| MCU 复位 | 所有继电器默认断开，电磁锁关闭，推杆停止 |
| 急停 | K1、K3～K8 断开，推杆停止，电磁锁关闭；K2 仅保留温度保护或传感器故障下的强制散热，不接受 CAN 强制开启 |
| 任一支路保护动作 | 对应输出关闭并锁存故障；未查明短路原因前不自动重试 |
| 电磁锁过流/短路 | 立即关闭并记录故障 |
| 推杆过流/堵转 | 立即停止，不自动反向 |
| 推杆动作超时 | 停止并记录故障 |
| 温湿度传感器掉线 | 风扇默认开启 |
| 4G 无响应 | 退出当前 AT 状态，重试或复位模块 |
| CAN 超时 | 相关受控功能进入安全默认状态 |
| 看门狗超时 | 硬件复位 MCU |

K2～K8 没有触点反馈时，软件不能确认触点是否实际吸合，只记录控制命令和线圈驱动状态。K1 应通过输出电压检测或诊断型开关确认上位机电源域实际得电。

## 8. 电源监控和保护

教育版不采用 FS26，采用成本更低的分立方案：

- 12V 输入 TVS 和反接保护
- 靠近源端的主保护，以及 K1～K8、电磁锁、推杆和板载电源的分支短路/过流保护
- 12V→5V DC/DC
- 12V→4.0V、≥3A 的 4G 专用 DC/DC
- 5V→3.3V Buck，或经最坏温升证明可接受的其它稳压方案
- 3.3V 电源监控和复位芯片
- 独立硬件看门狗
- MCU ADC 监测必要的电源电压

本版本不要求正式 EMC/ESD 认证测试，但仍保留基础的 TVS、输入滤波、接口限流和 ESD 防护设计。

## 9. 软件架构

采用轻量化 FreeRTOS 和事件驱动相结合的结构，避免为每个小功能单独创建任务。

```text
Bootloader
├── SWD 下载
└── CAN Bootloader

BSP/HAL
├── GPIO
├── FDCAN
├── UART DMA
├── SPI
├── I2C
├── ADC
├── Timer
└── Low Power

Drivers
├── Relay Driver
├── Smart High-Side Lock Driver
├── MC33926 Driver
├── SHT31 Driver
├── EG800Z Driver
└── Watchdog/Supervisor Driver

Services
├── Event Manager
├── Fault Manager
├── Parameter Manager
├── NVM Storage
└── Diagnostic Manager

Application
├── BCM State Manager
├── Power Manager
├── Light Manager
├── Fan Manager
├── Lock Manager
├── Actuator Manager
└── Wake/Sleep Manager
```

建议只保留四类任务：

| 任务 | 主要职责 |
|---|---|
| Safety/Control Task | 1ms 安全输入、继电器输出、推杆和电磁锁保护 |
| CAN Task | CAN 接收、发送、超时和事件分发 |
| 4G Task | EG800Z AT 状态机和远程通信 |
| Service Task | 温湿度、诊断、参数、故障记录和低功耗管理 |

软件要求：

- 静态内存分配
- DMA 优先
- 中断中只做采样、入队和置位，不执行复杂业务
- 所有输出通过统一接口控制，不允许业务层直接操作 GPIO
- 所有参数具有默认值、范围检查和版本管理
- 故障记录支持事件触发保存
- 自研 CAN Bootloader 具备镜像 CRC/签名、版本检查、断电恢复和失败回滚策略

## 11. 环境和结构要求

- 工作温度目标：-15～55℃，需通过器件温度等级、热设计和整机测试验证
- 防泼溅目标需由外壳、密封、连接器、透气与冷凝设计共同验证
- 建议采用带密封外壳
- PCB 建议做三防涂层
- BCM PCB 首版目标外形：**140 mm × 100 mm**；该尺寸当前仅为机械目标，必须在导入真实继电器、35P 母座、4G 模块、支路保护、DC/DC、安装孔和外壳 3D 模型后才能判断是否可行
- 继电器沿长边排列，连接器、电源入口、DC/DC 和 4G 模块必须在布局阶段做 3D 干涉检查；安装孔、边缘禁布区和插拔空间不能挤占功率回路
- 所有正式对外车载线束统一汇入一个多针防水汽车母座 `J_BCM_EXT`；`K776280WV-35-PTSNB`（C2997460）仅为候选，最终型号、物理针号、端子压接和外壳配套需按厂家受控图纸与样件验证冻结
- `J_BCM_EXT` 的 +12V/GND 和 K1～K8 触点输出针脚按 15A 连续、20A 短时峰值及各路 2A 上限校核，并与 UART/CAN 等小电流针脚分区

裸 PCB 本身不能等同于防泼溅结构，最终防护能力由外壳、密封件、连接器和 PCB 涂层共同决定。

## 12. 当前不冻结的内容

以下内容均未冻结，其中功率、安全、Pinmap、连接器和机械相关项是原理图/Gerber 放行阻断项：

1. CAN 报文 ID、信号定义、周期和超时值
2. CAN 速率和是否启用 CAN FD 数据段
3. 电磁锁干节点实际为常开还是常闭
4. 具体继电器型号，以及 `J_BCM_EXT` 候选件的最终封装、物理针号、端子压接规格、板端/线束端配对和防水件
5. 覆盖实际电池全电压范围的外部 12V DCDC 最终型号
6. 140 mm × 100 mm 板框内的安装孔、定位基准、连接器朝向和外壳干涉关系
7. 各继电器触点输出、电磁锁、推杆和低压信号的最终线束规格
8. K1～K8 实际负载矩阵、支路保护额定值和 15A/20A 总预算闭合记录
9. MCU Pinmap、低功耗 CAN 唤醒路径和自研 Bootloader 分区/回滚方案
10. 推杆内置限位/位置反馈能力；若需外置双限位，35P 针脚和连接器方案必须重新冻结

除上述接口细节外，教育版 BCM 的功能范围、主控、电源拓扑、继电器数量和软件总体框架可作为后续设计输入；功率分配、支路保护、Pinmap、低功耗唤醒、机械空间和关键器件型号未闭合前不得宣称原理图或 PCB 已定稿。
