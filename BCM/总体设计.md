# BCM 教育版总体设计

**文档状态：方案定稿（接口、功率边界与板框修订）**  
**版本：V1.2**  
**日期：2026-09-16**

## 1. 设计目标

本 BCM 用于教育版四轮四转机器人底盘，负责车身灯光、上位机电源域、风扇、推杆、电磁锁、温湿度监测、4G 唤醒和 CAN 通信。

本版本采用 STM32 主控和继电器输出方案，取消原设计中的 20 路智能高边灯光输出，保留一条电磁锁智能高边通道和一套 MC33926 推杆 H 桥。

机械臂控制器不由 BCM 直接控制，仅预留 CAN 接口。

## 2. 总体结论

### 2.1 主控

| 项目 | 定案内容 |
|---|---|
| MCU | STM32G491VET6 |
| 封装 | LQFP-100 |
| 主频 | 最高 170 MHz |
| Flash | 512 KB |
| 主要资源 | 双 FDCAN、ADC、SPI、I2C、UART、DMA、定时器 |
| 下载升级 | SWD + CAN Bootloader |

### 2.2 电源架构

BCM 只有一个外部电源输入：**12V**。

车辆 48～54V 电池到 12V 的大功率转换由外部 DCDC 完成。BCM 板上只完成低压电源转换和负载控制。

```text
48～54V 电池
      │
      ▼
外部大功率 DCDC
      │ 12V
      ▼
BCM 单路 12V 输入
      ├── K1～K8 继电器触点及 12V 负载
      ├── 电磁锁智能高边
      ├── MC33926 推杆 H 桥
      ├── 12V → 4.0V：EG800Z-GL
      ├── 12V → 5V：外设电源
      └── 5V → 3.3V：STM32、SHT31、逻辑电路
```

板载降压必须使用 DC/DC 或稳压模块，不能使用电阻分压为 MCU、4G 或其他负载供电。

外部 12V DCDC 不按 60A 或 70～80A 选型。结合本教育版小车的实际负载，BCM 的 12V 输入首版按 **15A 连续、20A 短时峰值**进行输入连接器、反接保护、主干铜结构和热设计校核。该预算包含板载电源、继电器线圈、电磁锁、推杆和已定义的继电器负载组合；每路继电器触点虽然允许不超过 2A，但不把 8 路同时满载 2A 作为首版使用工况。上电前仍需用实际负载实测确认启动峰值和最坏同时开启组合。

### 2.3 继电器数量

共使用 8 路 12V 继电器：

| 继电器 | 控制对象 | 设计电流 |
|---|---|---:|
| K1 | 上位机、功放、显示板、摄像头组、路由器 | ≤2A |
| K2 | 风扇 | ≤2A |
| K3 | 前灯一体 | ≤2A |
| K4 | 后灯一体 | ≤2A |
| K5 | 左转向灯 | ≤2A |
| K6 | 右转向灯 | ≤2A |
| K7 | 自动驾驶灯 | ≤2A |
| K8 | 巡逻灯 | ≤2A |

继电器统一采用 12V 线圈。每路触点按不超过 2A 的实际负载设计；继电器线圈由 BCM 板内 12V 供电并由 STM32 经 MOS 管低边驱动。触点通断输出线从统一车载母座引出，不能把触点输出线误当成线圈供电线。

所有继电器线圈由 STM32 通过 MOS 管低边驱动，并在线圈两端增加续流保护。

本版本不设置支路保险，不设置继电器触点反馈，也不检测 K1 输出电压。上游电源保护、主线保护和负载自身保护由整车电源系统及负载端负责。

## 3. 功率预算

| 功能 | 最大设计电流 |
|---|---:|
| K1～K8 继电器触点输出 | 约 10～12A 首版负载组合；每路不超过 2A |
| 电磁锁智能高边 | 5A 预留，实际约 1A |
| 推杆 MC33926 | 5A 预留，实际约 1A |
| 板载 DC/DC、MCU、4G 和继电器线圈 | 按实际器件和启动峰值核算 |
| BCM 12V 输入设计目标 | 15A 连续、20A 短时峰值 |

继电器触点公共电源与板载 DC/DC 共用 BCM 的 12V 输入电源域，但触点输出线和线圈驱动线必须在原理图、连接器针脚和 PCB 区域上明确区分。12V 输入正负极、继电器触点公共电源分配和各路触点输出按 15A 连续、20A 短时峰值校核；不能再按 65～70A 设计，也不能让继电器线圈电源占用触点输出针脚。若实测负载组合超过 12A 连续或 20A 短时峰值，必须重新核算外部 DCDC、连接器和铜结构，不能靠软件“默认少开几路”来掩盖电源不足。

## 4. 负载和控制逻辑

### 4.1 K1 上位机电源域

K1 同时给以下设备供电：

- 上位机
- 功放
- 显示板
- 摄像头组
- 路由器

K1 设计电流不超过 2A。K1 采用一个继电器统一控制，不再为上述设备分别设置继电器。K1 的线圈供电由 BCM 板内 12V 提供，K1 触点的通断输出通过统一车载母座引出。

EG800Z-GL 不由 K1 控制，使用 BCM 常电待机电源单独供电，以支持远程唤醒。

### 4.2 风扇

风扇由 K2 控制。

- 正常情况下由温度、湿度阈值控制
- 阈值可由上位机设置
- 必须设置开启和关闭回差
- 支持 CAN 强制开启
- 任一关键温湿度传感器掉线时，风扇默认开启
- K2 不做触点反馈

推荐控制优先级：

```text
急停输出策略（见第 7 章）
        > 传感器故障强制开启
        > CAN 强制开启
        > 温湿度自动控制
```

### 4.3 灯光

灯光全部采用继电器通断控制，不由 STM32 生成闪烁波形。

- 前灯和后灯允许同时开启
- 左转和右转允许同时开启，实现双闪
- 转向灯为通电自闪型
- 自动驾驶灯在自动驾驶模式下自动开启
- 巡逻灯由上位机控制
- 不实现灯光闪烁算法
- 不保留三色模式指示灯
- 上装灯取消

### 4.4 电磁锁

电磁锁采用 1 路独立智能高边开关：

- 实际工作电流约 1A
- 按 5A 能力预留
- 通电上锁
- 断电开锁
- 继电器急停策略不适用于电磁锁，电磁锁由独立智能高边控制
- 过流、短路或急停时立即关闭

电磁锁为四根线：

```text
两根：锁电源线
两根：干节点锁状态反馈线
```

反馈输入不向锁反馈线主动供电，采用隔离/限流/上拉后的数字输入方式。默认按“上锁完成后干节点闭合”处理，并在软件中保留有效电平配置和消抖。

### 4.5 上盖推杆

推杆使用 MC33926 H 桥控制，电机只有两根线，通过交换正负极改变方向。

```text
OPEN   ：正向运行
CLOSE  ：反向运行
STOP   ：停止
```

推杆实际电流约 1A，堵转电流不超过 5A。

“不自动反向”的含义：

- 开启过程中不会自动切换为关闭
- 关闭过程中不会自动切换为开启
- 过流、堵转或超时后只停止，不自动反向
- 收到新的反向命令时，先停止，再经过短暂死区，最后允许改变方向

推杆保留 MC33926 电流反馈 ADC，用于过流、堵转和动作超时判断。

### 4.6 机械臂

机械臂不由 BCM 直接控制，不占用继电器和高边输出资源，仅预留 CAN 接口供后续扩展。

## 5. 通信和接口

### 5.1 主干 CAN 和预留 CAN

STM32G491 的两路 FDCAN 分配如下：

| 接口 | 用途 |
|---|---|
| CAN1 | 主干 CAN FD |
| CAN2 | 预留 CAN，后续可接机械臂等设备 |

CAN 报文 ID、信号定义、周期、超时时间、CRC 和 Alive Counter 暂不冻结，后续根据整车通信协议确定。软件先提供统一 CAN 驱动、报文队列、信号打包和解包接口。

### 5.2 4G 模块

模块：EG800Z-GL。

软件采用：

- UART DMA 接收
- 环形缓冲区
- 非阻塞 AT 命令状态机
- AT 命令队列
- 响应匹配和超时重试
- 远程唤醒
- 状态通信

本版本暂不实现 4G OTA。

### 5.3 温湿度传感器

两个 SHT31 共用一路 I2C：

| 地址 | 用途 |
|---|---|
| 0x44 | 舱内温湿度 |
| 0x45 | 控制板区域温湿度 |

驱动需要包含 CRC 校验、掉线检测、合理范围检查、数据滤波和传感器状态管理。

### 5.4 唤醒输入

支持三类唤醒来源：

- EG800Z-GL 4G 唤醒
- 主干 CAN 唤醒
- 外部唤醒输入

外部唤醒输入采用带限流、滤波和过压保护的数字输入电路。

### 5.5 其他输入

保留以下输入功能：

- 急停状态输入
- 电磁锁干节点反馈输入
- 推杆 MC33926 故障输入
- 推杆电流 ADC 输入

### 5.6 车载线束接口统一要求

BCM 所有正式对外车载线束统一使用一个带锁止、防水、防呆的多针汽车母座，逻辑编号为 `J_BCM_EXT`。不再设置第二个 BCM 车载母座。

`J_BCM_EXT` 在同一个壳体内按功能分组分针脚：

- 大电流/功率针脚：BCM 板载 `+12V_IN`、`GND`，K1～K8 继电器触点通断输出和两根推杆电机输出；`+12V_IN` 与 `GND` 首版各使用 4 个并联针脚，禁止用单个 7A 标称针脚承载整板输入；
- 板载 DC 输出针脚：对外只预留按需使用的 `5V`、`3V3` 及回流；EG800Z-GL 专用 `4V0` 默认只在板内使用，不直接引出到长线束；
- 小电流信号针脚：CAN1、CAN2、外部 UART、唤醒、急停、锁反馈及其它低压控制信号；推杆控制、故障和电流采样保持板内连接，不占用车载母座针脚；
- 继电器线圈供电和线圈驱动不作为对外接口，全部由 BCM 板内完成；
- 触点输出线、板载 DC 电源线和信号线必须使用不同针脚并在原理图、丝印、线束表中清楚标识，不能因为共用一个母座而在电气上混接。

嘉立创商城已查到优先候选：[K776280WV-35-PTSNB（C2997460）](https://item.szlcsc.com/3468812.html)，4 mm 间距、三排 35P、直针、防水、PBT，页面标称额定电流 7A，核查时现货 139 个。配套资料列出的线束侧针座为 `K776231WV-1`、胶壳为 `K776164H-1`、端子为 `K770520T-1`。该型号可作为首版母座候选，但正式投板前必须用厂家图纸核对焊盘、端子、胶壳、防水塞、线径和相邻针脚温升；“7A”不能直接等同于整座连接器可承载 7A 以上。

35P 的首版逻辑分配为：`+12V_IN` 4 针、`GND` 4 针、K1～K8 8 针、`5V/GND` 2 针、`3V3/GND` 2 针、CAN1 2 针、CAN2 2 针、CAN 公共参考 1 针、外部 UART 2 针、唤醒 1 针、急停 2 针、锁反馈 2 针、推杆电机 2 针、备用 1 针，共 35 针。最终物理针号按实际封装图冻结。

EG800Z-GL 与 MCU 的板内 UART 仍保持板内连接；若有其它 UART 需要对外引出，统一使用 `J_BCM_EXT` 的小电流针脚。SWD、串口日志和生产测试仅保留为密封外壳内的测试焊盘或测试夹具。若舱内 SHT31 不安装在 BCM 板上，不能把裸 I2C 作为长距离车载线束直接引出；应采用短线本地传感器子板或经评估的抗干扰转换方案。

4G 天线如需出壳，板内可使用 U.FL/IPEX 等专用 50Ω 射频连接，外壳处使用密封射频穿墙件；该射频通道不替代也不使用多芯车载线束连接器。

## 6. 状态机

BCM 主状态建议如下：

```text
INIT → SELF_CHECK → STANDBY
                    │
                    ├── 唤醒事件 → WAKE_REQUEST → SELF_CHECK → POWER_ON → NORMAL_RUN
                    │                                            │             ├── DEGRADED_RUN
                    │                                            │             └── FAULT
                    └── 休眠条件 → SLEEP
```

STANDBY 和 SLEEP 都可由 4G、主干 CAN 或外部唤醒输入触发并进入 `WAKE_REQUEST`，随后执行自检；这样与待机/休眠阶段保留的唤醒能力保持一致。

### 6.1 待机

待机状态只保持必要的 MCU、监控电路和 EG800Z-GL 电源。K1～K8 默认断开，电磁锁和推杆默认关闭。

### 6.2 唤醒

4G、主干 CAN 或外部唤醒输入产生有效事件后，BCM 唤醒并执行自检。自检完成后，根据上位机和整车状态控制 K1～K8。

### 6.3 运行

运行状态中执行继电器控制、灯光逻辑、风扇控制、推杆控制、电磁锁控制、CAN 通信和 4G 状态通信。

### 6.4 休眠

满足休眠条件时：

- K1～K8 断开
- 电磁锁高边关闭
- 推杆停止
- 保留 MCU 低功耗唤醒能力
- 保留 EG800Z-GL 远程唤醒能力

## 7. 故障策略

按教育版默认故障策略执行：

| 故障 | 处理 |
|---|---|
| MCU 复位 | 所有继电器默认断开，电磁锁关闭，推杆停止 |
| 急停 | K1、K3～K8 断开，推杆停止，电磁锁关闭；K2 仅保留温度保护或传感器故障下的强制散热，不接受 CAN 强制开启 |
| 电磁锁过流/短路 | 立即关闭并记录故障 |
| 推杆过流/堵转 | 立即停止，不自动反向 |
| 推杆动作超时 | 停止并记录故障 |
| 温湿度传感器掉线 | 风扇默认开启 |
| 4G 无响应 | 退出当前 AT 状态，重试或复位模块 |
| CAN 超时 | 相关受控功能进入安全默认状态 |
| 看门狗超时 | 硬件复位 MCU |

由于 K1～K8 不做触点反馈，软件不能确认继电器触点是否实际吸合，只记录控制命令和继电器线圈驱动状态。

## 8. 电源监控和保护

教育版不采用 FS26，采用成本更低的分立方案：

- 12V 输入 TVS 和反接保护
- 12V→5V DC/DC
- 12V→4.0V、≥3A 的 4G 专用 DC/DC
- 5V→3.3V 稳压
- 3.3V 电源监控和复位芯片
- 独立硬件看门狗
- MCU ADC 监测必要的电源电压

本版本不要求正式 EMC/ESD 认证测试，但仍保留基础的 TVS、输入滤波、接口限流和 ESD 防护设计。

## 9. 软件架构

采用轻量化 FreeRTOS 和事件驱动相结合的结构，避免为每个小功能单独创建任务。

```text
Bootloader
├── SWD 下载
└── CAN Bootloader

BSP/HAL
├── GPIO
├── FDCAN
├── UART DMA
├── SPI
├── I2C
├── ADC
├── Timer
└── Low Power

Drivers
├── Relay Driver
├── Smart High-Side Lock Driver
├── MC33926 Driver
├── SHT31 Driver
├── EG800Z Driver
└── Watchdog/Supervisor Driver

Services
├── Event Manager
├── Fault Manager
├── Parameter Manager
├── NVM Storage
└── Diagnostic Manager

Application
├── BCM State Manager
├── Power Manager
├── Light Manager
├── Fan Manager
├── Lock Manager
├── Actuator Manager
└── Wake/Sleep Manager
```

建议只保留四类任务：

| 任务 | 主要职责 |
|---|---|
| Safety/Control Task | 1ms 安全输入、继电器输出、推杆和电磁锁保护 |
| CAN Task | CAN 接收、发送、超时和事件分发 |
| 4G Task | EG800Z AT 状态机和远程通信 |
| Service Task | 温湿度、诊断、参数、故障记录和低功耗管理 |

软件要求：

- 静态内存分配
- DMA 优先
- 中断中只做采样、入队和置位，不执行复杂业务
- 所有输出通过统一接口控制，不允许业务层直接操作 GPIO
- 所有参数具有默认值、范围检查和版本管理
- 故障记录支持事件触发保存

应用层使用逻辑通道，不直接绑定 MCU 引脚：

RELAY_LEFT_TURN

推荐的控制接口包括：

## 11. 环境和结构要求

- 工作温度：-15～55℃
- 具备防泼溅能力
- 建议采用带密封外壳
- PCB 建议做三防涂层
- BCM PCB 首版目标外形：**140 mm × 100 mm**；该尺寸对当前 8 路继电器、单个 35P 边缘母座、4G 模块、DC/DC 和功率分区可行，并为连接器插拔、安装孔和散热留出合理余量
- 继电器沿长边排列，连接器、电源入口、DC/DC 和 4G 模块必须在布局阶段做 3D 干涉检查；安装孔、边缘禁布区和插拔空间不能挤占功率回路
- 所有正式对外车载线束统一汇入一个多针防水汽车母座 `J_BCM_EXT`；首版优先采用嘉立创候选 `K776280WV-35-PTSNB`（C2997460），最终物理针号、端子压接和外壳配套需按厂家图纸/样件冻结
- `J_BCM_EXT` 的 +12V/GND 和 K1～K8 触点输出针脚按 15A 连续、20A 短时峰值及各路 2A 上限校核，并与 UART/CAN 等小电流针脚分区

裸 PCB 本身不能等同于防泼溅结构，最终防护能力由外壳、密封件、连接器和 PCB 涂层共同决定。
