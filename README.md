# Car--infinite-edu

四轮四转机器人底盘教育版项目，包含两个相互独立、通过 CAN FD 协同工作的控制单元：

- **VCU**：车辆控制单元，负责底盘运动、安全和执行器控制；
- **BCM**：车身控制模块，负责车身电源、灯光、推杆、电磁锁、环境监测和 4G 唤醒。

## 系统边界

| 单元 | 主要职责 | 不负责的内容 |
|---|---|---|
| 上位机 | 下发底盘目标、设置 BCM 参数、发送巡逻灯等车身请求 | 不直接控制单个电机 |
| VCU | 四轮四转解算、转向与驱动控制、底盘状态、安全状态机、本地硬件急停 | 不直接驱动车身灯光和外围负载 |
| BCM | 上位机电源域、风扇、8 路继电器、灯光、电磁锁、推杆、温湿度、4G 唤醒 | 不绕过 VCU 控制四轮转向或四轮驱动 |

## 主要通信关系

```text
上位机 ─┐
        ├── 主干 CAN FD ── VCU
BCM ────┘

VCU ── 独立 CAN ── 转向电机
VCU ── CANopen ── 驱动器
```

BCM 使用 CAN1 接入与上位机、VCU 共用的主干 CAN FD，CAN2 作为后续扩展接口。主干 CAN FD 的具体 ID、信号、周期、超时、CRC 和 Alive Counter 待整车通信协议确定。

## 车载接口统一原则

BCM 和 VCU 的正式对外车载线束接口统一使用带锁止、防水和防呆结构的汽车连接器。统一的是接口类别和设计规范，不要求所有接口使用同一针数或同一系列：低压信号、CAN、急停、传感器和负载接口按信号数选型；BCM 的 12V 主输入和 K1 30A 回路必须使用独立的大电流防水汽车连接器或等效的大电流防水连接结构。

UART 是电气通信协议，不是连接器规范。BMS、超声波、ToF、4G 模块等 UART 信号不得以 2.54mm 4 芯 UART 母头作为正式车载接口引出。SWD、串口日志和生产测试仅保留在密封外壳内的测试焊盘、测试夹具或临时维护接口中。

防水汽车连接器的具体系列、针数、端子规格、板端/线束端配对、线径、额定电流、温度范围、插拔寿命和防护等级在原理图与线束图阶段冻结；首版物料优先选择嘉立创可稳定采购、资料可追溯的型号。防水连接器本身不等同于整板“车规级”，还必须按数据手册和样件验证端子压接、锁止、防呆、空腔堵头、线束固定、温升、振动和插合后的防水能力。射频天线的 50Ω 同轴连接属于专用 RF 通道，可在板内使用 U.FL/IPEX，并通过密封射频穿墙件引出，不属于多芯车载线束接口。

## 安全边界

VCU 是底盘运动的唯一控制中心。本地两线常闭急停及 VCU 硬件安全门控优先级最高；BCM 的急停输入用于关闭车身非必要输出、停止推杆和电磁锁，不替代 VCU 的电机硬件急停链路。
