# Car--infinite-edu

四轮四转机器人底盘教育版项目，包含两个相互独立、通过 CAN FD 协同工作的控制单元：

- **VCU**：车辆控制单元，负责底盘运动、安全和执行器控制；
- **BCM**：车身控制模块，负责车身电源、灯光、推杆、电磁锁、环境监测和 4G 唤醒。

## 系统边界

| 单元 | 主要职责 | 不负责的内容 |
|---|---|---|
| 上位机 | 下发底盘目标、设置 BCM 参数、发送巡逻灯等车身请求 | 不直接控制单个电机 |
| VCU | 四轮四转解算、转向与驱动控制、底盘状态、安全状态机、本地硬件急停 | 不直接驱动车身灯光和外围负载；轴距、轮距、轮半径等几何参数待实车测量标定 |
| BCM | 上位机电源域、风扇、8 路继电器、灯光、电磁锁、推杆、温湿度、4G 唤醒 | 不绕过 VCU 控制四轮转向或四轮驱动 |

## 主要通信关系

```text
上位机 ─┐
        ├── 主干 CAN FD ── VCU
BCM ────┘

VCU ── 独立 CAN ── 转向电机
VCU ── 厂家自定义经典 CAN（SDO-like，非 CANopen）── 两台 MSSD-100EMA_2EC_N
```

BCM 使用 CAN1 接入与上位机、VCU 共用的主干 CAN FD，CAN2 作为后续扩展接口。主干 CAN FD 的具体 ID、信号、周期、超时、CRC 和 Alive Counter 待整车通信协议确定。

VCU 的 CAN3 接两台 MSSD-100EMA_2EC_N 一拖二驱动器。厂家 V1.0 协议明确为 CAN 2.0A、11 位标准数据帧，默认 500kbps/节点 1，数据格式借用 SDO 风格但暂不支持 CANopen。两台设备接入前必须分别设置唯一节点 ID；不得假设 CiA 402、NMT、PDO、Heartbeat 或 EDS 可用。商户称支持状态主动上报，但当前资料缺少报文 ID、周期和载荷定义，仍待正式协议补充。

BCM 电磁锁候选已取得 SM60E 规格图：12V 版为 92mA/1.1W，红黑两根功率线，另有双白“无磁信号反馈”；反馈电气类型及其是否代表机械贴合尚未定义。推杆只有商户口述的两线换极反转、断电停止和双端内置限位，完整型号、电流、行程、推力与保持能力仍未取得。

## 车载接口统一原则

BCM 和 VCU 的正式对外车载线束接口统一使用带锁止、防水和防呆结构的汽车连接器。BCM 当前采用一个多针汽车母座统一承载板载 12V 正负极、K1～K8 继电器触点输出、电磁锁功率线、推杆电机线和 UART/CAN/控制信号；不同功能使用不同针脚并按各自电流校核，不再设置第二个 BCM 车载母座。首版不从该母座引出未定义用途的 5V/3V3。BCM 首版按 15A 连续、20A 短时峰值目标设计，+12V/GND 各使用多个并联针脚，但必须用实际负载、端子降额和温升试验闭合预算。VCU 首版按 12V 输入 3A 连续、5A 短时峰值设计，四个驱动轮和四个转向执行器的动力电源不经过 VCU PCB。

BCM 的 2A 支路必须由板载或靠近电源源端的保险、eFuse 或等效保护单独保护；15A/20A 主保护不能替代支路线束保护。

UART 是电气通信协议，不是连接器规范。BCM 对外 UART 若有需要，统一放在同一个多针防水汽车母座的小电流针脚组中，不增加专用 4 芯母头。BMS、超声波、ToF、4G 模块等 UART 信号不得以 2.54mm 4 芯 UART 母头作为正式车载接口引出。SWD、串口日志和生产测试仅保留在密封外壳内的测试焊盘、测试夹具或临时维护接口中。

BCM 已查到嘉立创商城候选 [K776280WV-35-PTSNB（C2997460）](https://item.szlcsc.com/3468812.html)，4 mm、三排 35P、直针、防水、PBT，页面标称 7A/触点；VCU 小信号可评估 `DL20023`/`JWPF` 2 mm、IPX7 系列。商城信息只用于初筛，具体端子、线束侧胶壳、物理针号和主电源连接器必须依据厂家受控图纸、生命周期资料和样件验证后冻结。防水汽车连接器本身不等同于整板“车规级”，还必须验证端子压接、锁止、防呆、空腔堵头、线束固定、同时载流温升、振动和插合后的防水能力。射频天线的 50Ω 同轴连接属于专用 RF 通道，可在板内使用 U.FL/IPEX，并通过密封射频穿墙件引出，不属于多芯车载线束接口。

## 安全边界

VCU 是底盘运动的唯一控制中心。本地急停及 VCU 硬件安全门控优先级最高，并且必须覆盖四个驱动轴和四个转向轴；只关闭驱动轮控制器不构成完整急停。BCM 的急停输入用于关闭车身非必要输出、停止推杆和电磁锁，不替代 VCU 的电机硬件急停链路。当前两线单通道常闭方案仅适用于受控的教育验证；涉及人员保护时必须使用经过风险评估的双通道安全回路。
