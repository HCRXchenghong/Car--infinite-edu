# Car--infinite-edu

四轮四转机器人底盘教育版项目，包含 VCU 与 BCM 两个相互独立、通过 CAN FD 协同工作的控制单元。

## 目录结构

```text
.
├── VCU/    车辆控制单元：底盘解算、执行器控制、传感器、无线遥控和安全状态机
└── BCM/    车身控制模块：预留目录，后续补充 BCM 硬件、软件和通信设计
```

## 当前内容

- [VCU 总体架构设计](VCU/总体架构设计.md)
- [BCM 预留说明](BCM/README.md)

## 系统边界

上位机只向 VCU 下发底盘级速度目标；VCU 完成四轮四转解算、转向与驱动控制、故障管理和急停锁存。BCM 与 VCU 共用一条 CAN FD 总线，交换车身状态、使能和安全联锁信息。
