# Car--infinite-edu

四轮四转机器人底盘教育版项目，包含两个相互独立、通过 CAN FD 协同工作的控制单元：

- **VCU**：车辆控制单元，负责底盘运动、安全和执行器控制；
- **BCM**：车身控制模块，负责车身电源、灯光、推杆、电磁锁、环境监测和 4G 唤醒。

## 系统边界

| 单元 | 主要职责 | 不负责的内容 |
|---|---|---|
| 上位机 | 下发底盘目标、设置 BCM 参数、发送巡逻灯等车身请求 | 不直接控制单个电机 |
| VCU | 四轮四转解算、转向与驱动控制、底盘状态、安全状态机、本地硬件急停 | 不直接驱动车身灯光和外围负载 |
| BCM | 上位机电源域、风扇、8 路继电器、灯光、电磁锁、推杆、温湿度、4G 唤醒 | 不绕过 VCU 控制四轮转向或四轮驱动 |

## 主要通信关系

```text
上位机 ─┐
        ├── 主干 CAN FD ── VCU
BCM ────┘

VCU ── 独立 CAN ── 转向电机
VCU ── CANopen ── 驱动器
```

BCM 使用 CAN1 接入主干 CAN，CAN2 作为后续扩展接口。主干 CAN 的具体 ID、信号、周期、超时、CRC 和 Alive Counter 待整车通信协议确定。

## 安全边界

VCU 是底盘运动的唯一控制中心。本地两线常闭急停及 VCU 硬件安全门控优先级最高；BCM 的急停输入用于关闭车身非必要输出、停止推杆和电磁锁，不替代 VCU 的电机硬件急停链路。
