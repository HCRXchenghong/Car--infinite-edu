# PCB 与制造要求

## 1. 机械与层叠基线

VCU 130×90mm、BCM 140×100mm 只是面积目标。未导入真实连接器、继电器、模块、安装孔和壳体 3D 前，不用此尺寸承诺可装下。先提交布局草图和高度图，再冻结板框。

优先 4 层：L1 器件/关键线，L2 连续 GND，L3 电源分区，L4 辅助信号/功率。VCU 可从外层 1oz 起评估；BCM 可从外层 2oz、内层 1oz 起评估。铜厚、介质和叠层必须和板厂确认，不是投板默认参数。

BCM 15～20A 路径采用宽面/多层并联铜及足够连接过孔，必要时铜条/汇流结构。不能用一条“2mm 宽线”笼统声称承载 20A。用 IPC-2152 或经验证方法加温升实测决定宽度/铜面积；过孔并联电流同样不能按平均值忽略不均流和焊盘瓶颈。

## 2. 区域与放置次序

| 板 | 放置优先级 | 不可邻近/交叉 |
|---|---|---|
| VCU | 连接器/孔位 → 输入保护 → Buck → MCU/去耦 → MAX/时钟 → 收发器 → RF → 安全接口 | RF/晶体远离 Buck；外部干扰线不穿 MCU 下方 |
| BCM | 35P/孔位 → 保险/功率汇流 → 继电器 → H 桥/锁 → Buck → MCU → 4G/SIM/RF → SHT | SHT 远离热源；RF 不跨功率回流；H 桥不共用 ADC 窄地 |

连接器面向外壳可维护方向，不让壳壁挡锁扣。插件焊接区、散热底焊盘、调试夹具和工具空间必须预留。保险可更换时要能取出，但不能让用户直接接触带电母线。

## 3. 网络分级和布线规则

| 类别 | 例子 | 规则 |
|---|---|---|
| 逻辑信号 | SPI/UART/控制 | 优先短线、连续地参考；工艺起始线宽/间距可 0.20mm，最终按板厂及电压规则 |
| 模拟 | ADC/FB/VDDA | 远离开关节点与负载回流，Kelvin 接地；滤波靠 ADC |
| CAN | H/L | 配对、少过孔、无长分叉、保护靠接口；阻抗目标与线束/叠层联合确认 |
| RF | LTE/天线线 | 50Ω 单端受控阻抗，按实际叠层计算；同层地与过孔围栏按模块指南 |
| 电源 | 12V 主路、继电器触点 | 根据电流、铜厚、允许温升计算，逐瓶颈复核 |
| H 桥 | OUT1/OUT2/VPWR/PGND | 紧凑大电流回路；多脚全连，避免地弹污染逻辑 |
| 安全 | ESTOP/WD/PERMIT | 明确默认态和测试点，避免与高噪声线平行；不靠 0Ω 常装绕过门控 |

板上不承载 48V 动力，但 12V 瞬态/外部故障电压仍决定间距与耐压。上述 0.20mm 只是低压工艺起点，不代表安全绝缘认证或所有网络通用间距。

不要为了“模拟地干净”将 L2 切出狭缝迫使 CAN/SPI 回流绕路。功率与信号通过布局引导回流；需要单点的器件 AGND/PGND 按其参考布局在本地连接，整板不机械套用任意星形细线地。

## 4. 必查封装和底焊盘

- MCU 必须核实 LQFP128/LQFP100 的本体、引脚间距、脚 1 朝向与焊盘编号；不得仅按库名相同判断。
- MAX14830 TQFN48 的 EP 接 AGND；芯片 46 脚 AGND 同时存在并连接；钢网开窗和热过孔防吸锡按厂商/板厂工艺。
- MC33926PNB 为 32 引脚 PQFN、8×8mm、图号 98ARL10579D；不可使用 HSOP footprint。EP/AGND 与多 PGND、VPWR、OUT 脚逐个核对；底视/顶视方向错误会损毁负载。
- TPSM53603 DNC 焊盘 4/5 各自孤立；NC 3/10/11 按参考接地；15 为功率底焊盘。不要统一用“NC 接地”规则处理。
- SOIC-8 CAN 与 VSON-8 不是同一 footprint；AV 与无 V 的 pin 5 功能不同。
- 继电器必须核对底视图/顶视图和 COM/NO/NC；同外壳不保证同脚序。
- 连接器孔径/焊盘/定位柱/锁扣/板边距离按受控机械图；照片和商城参数不够。
- nRF/4G 模块的禁布区、地焊盘、天线开口和最大高度按具体完整型号，不用通用方框代替。

## 5. ERC/DRC 与独立网表检查

ERC 不允许未解释的电源输入悬空、两个推挽输出相连、输入浮空、未驱动电源网。显式标记真正 NC；电源标志只能描述已存在电源，不能用来掩盖漏连。

逐网审查至少覆盖：每个电源脚/去耦、所有地、极性器件、H 桥多脚、晶体/时钟、SWD/复位/启动、安全默认态、UART 交叉、电平域、所有 CAN 终端、继电器线圈/触点、锁反馈/功率和连接器镜像。由第二人从 PDF 对照厂家脚表复核，不仅相信自动规则。

DRC 包括短路/间距/未连线、钻孔铜环、板边铜、铜到安装孔、阻焊桥、钢网与裸焊盘、回流完整性、反面器件高度和连接器焊接可达性。禁止保留未解释的“忽略警告”。

本包 MCU 校验工具只验证数据表内部一致性；没有真实 CAD 网表，不能替代 CAD ERC/DRC。

## 6. 生产包内容与版本一致性

| 文件 | 内容 | 复核重点 |
|---|---|---|
| SCH 源文件/PDF | 全部页面、位号、网络、修订 | 与 BOM/PCB 同版 |
| PCB 源文件/库 | 板框、铜层、机械、3D | 不依赖未交付私有库 |
| Gerber/ODB++ | 所有铜、阻焊、丝印、钢网、板框 | 独立 CAM 查看器检查 |
| NC Drill | PTH/NPTH 与槽孔 | 单位、原点、镀层标记 |
| BOM | 完整制造商/订货号/数量/封装/DNP/替代状态 | 无 H 项；不能把候选表当采购表 |
| CPL/XY | 位号、坐标、面、角度 | 以装配图确认旋转，不全依赖软件导出 |
| 装配图 | 两面极性、脚 1、手焊/插件/不装件 | 继电器/二极管/电解/模块方向 |
| 工艺单 | 叠层、铜厚、板厚、公差、阻抗、表面处理 | 与报价能力一致 |
| 测试包 | 测试点、夹具、流程、限值、空白记录 | 能追踪到板号与工单 |

命名建议：`VCU_HW_Rx_*`、`BCM_HW_Rx_*`。生产发布由设计人、复核人、制造责任人签字并生成文件 SHA256。首单先做小批工程样板，不在未测试情况下批量采购/贴片。

## 7. 装配、三防与返修

贴装前检查湿敏等级、存储/烘烤与回流曲线。不能在没有器件允许温度资料时统一按某温度回流。首件重点检查 QFN/PQFN 底焊盘空洞、连锡、翘脚；需要时 X-ray。

三防涂覆前完成清洁和功能验证；屏蔽连接器接触面、SWD 测试点、SHT 感应孔、RF 连接器、继电器要求排气孔和禁止涂覆的模块区域。不可用灌胶掩盖未解决的热问题。

返修更改位号/值/飞线必须写入变更记录并同步原理图/BOM/测试，不能只在样板上口头记忆。MC33926、TVS、保险等曾过热后要查上游根因，禁止只换保险继续试。
