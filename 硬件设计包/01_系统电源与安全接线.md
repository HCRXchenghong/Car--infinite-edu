# 系统电源与安全接线

## 1. 电源域与主线

以下是拓扑，不是具体接触器实体端子图。48V 电池实际满充电压、放电截止、BMS 断开行为、最大短路电流必须由电池资料确定，不能由“48～54V”几个字推定。

```text
电池正极 → 紧邻电池的主熔断器 → 维修断开装置 → 高压配电
  ├─ 动力支路保护/预充/受控接触器 → 驱动器和四个转向执行器
  └─ DCDC 输入保护 → 48V→12V DCDC → 12V 配电点
       ├─ F_VCU 源端保护 → VCU（逻辑与安全监督）
       ├─ F_BCM 源端保护 → BCM（常电、K1～K8、锁、推杆）
       └─ 其它经授权支路，不从 MCU 板临时搭电
电池负极/DCDC 参考地 → 按隔离策略形成配电回流点
```

1. 先确认 DCDC 是否隔离。隔离输出的负极是否与动力负极/机壳相连，只能由系统接地方案决定；禁止在多块板上随机重复短接。
2. MCU 板只接受受保护 12V，绝不接电池 48V。使用不同机械编码并明确丝印。
3. VCU 逻辑不能由 BCM K1 供电。K1 关闭上位机时 VCU 仍须有能力停止、监测执行器并报告故障。
4. 正极源端保险保护从源到负载的整段线束。仅在远端 PCB 装保险，不能保护其上游长线。
5. 主动力断开后，DC 母线电容仍可能有电；设置放电措施、验电点与等待时间，实际残压测量合格后才拆线。
6. DCDC 不一定能吸收回灌。推杆减速和驱动器制动能量必须由电容、制动电阻/控制器、允许回充的电池或经计算的吸收路径处理，不能默认 TVS 可反复耗散全部机械能。
7. S07 给 MSSD-100EMA_2EC_N 的额定输入为 DC 10～56V、极限输入为 DC 9～59V。必须用电池满充电压、回生抬升、接触器/线束瞬态和测量误差校核；例如 58.8V 满充已经高于 56V 额定值且几乎没有极限余量，不能因为商品写“48V”就直接接入。
8. S10 给 DM-J10010L-2EC 的接口说明为额定 24V、支持 24～48V，而参数表写额定 48V；项目只采用其共同可解释的 24～48V 供电范围，不把手册建议的 58V 过压门限当作允许输入上限。58.8V 满充不在标称支持范围内，未经厂家书面确认与台架瞬态/回生验证不得直连。
9. DM-J10010L 的 23.5A/95A 是相电流，不是 DC 母线连续/峰值电流；不能据此直接选保险、接触器、XT30 线径或电池。四台必须测 DC 输入启动、转向、堵转和回生波形后闭合动力预算。

### 1.1 四台 DM-J10010L-2EC 动力支路

厂家资料给每台电机两个 XT30 电源接口，允许用于多机串接走线并建议不超过 2 台。这里把“串接”理解为电源菊链走线，不解释成电机电气串联；四台电机不得串成一个未经校核的长支路。起始拓扑采用两条受保护支路、每支路最多两台，每条都由安全门控的 DC 接触器/安全继电器切断，并按实测 DC 电流选择独立熔断器、线径、端子和接触器分断能力。

```text
动力母线 → F_STEER_A → K_STEER_A（受硬件安全门控，有辅助反馈）→ STEER_FL → STEER_FR
动力母线 → F_STEER_B → K_STEER_B（受硬件安全门控，有辅助反馈）→ STEER_RL → STEER_RR
```

以上 FL/FR、RL/RR 只是待线束冻结的分组示例，不固定轴位。必须确认电源端口内部并联方式、XT30 连续/峰值额定、线束压降、接触器开断时的回生/母线抬升和失电后输出轴行为。未经确认，不在运动中直接硬切接触器作为常规制动动作；急停动作顺序由危害分析和实测停止结果冻结。

## 2. BCM 单座接口的回流闭环

```text
DCDC+ → BCM 四根等规格输入正线 → 板内保险/继电器 → Kx_OUT
Kx_OUT → 外部负载正极 → 外部负载负极 → 12V 配电地汇流排 → DCDC-
BCM 四根输入负线 → 同一个 12V 配电地汇流排
LOCK_OUT → 锁线圈 → LOCK_RETURN → BCM 功率地 → 输入负线
ACT_OUT1 → 推杆电机 → ACT_OUT2（浮动 H 桥输出，不接地）
```

35P 没有为八个继电器负载各提供负线。本基线明确采用外部负线汇流，不可误接到 `CAN1_REF/CAN2_REF/UART_REF/LOCK_SENSE_RETURN`。如果要求每个负载双线都从 BCM 母座发出，至少还需 8 个位置，当前 35P 不能满足，必须变更接口而非挤用信号地。

四根输入正线分别从同一配电点出发、同长度/截面/端子，不串接。负线也分别返回同一汇流点。平均 15A/4=3.75A 不代表每脚恰好 3.75A；需检查接触电阻偏差和一根脱落后的载流。不得带电拔插并联供电端子。

信号参考地只承受参考/均衡电流。考虑主负线断开但 CAN/UART 尚连接的故障：用隔离收发器、接地体系约束及具有限流/故障耐受的接口解决；不能把细信号地当作备用功率负线。若采用非隔离 CAN，必须实测最坏地电位差和断地电流，确认接口与线束不会烧毁，否则升级隔离方案。

## 3. 八轴安全链及再使能

四个驱动轴和四个转向轴分别列入验证表。普通 Enable、CAN Quick Stop、STO、抱闸和动力接触器的作用不同：STO 通常不主动制动；断电不保证坡上驻车；接触器不得在超出其 DC 分断额定条件下强制开断。

教育验证基线采用 NC 回路：断线或按下急停导致硬件许可失效。两线回路不能识别两线互短，也不能达到双通道人员防护等级。涉及夹伤、失控撞人、坡道和载人风险时，在车辆带动力前完成风险评估并选择有认证资料的双通道安全控制与执行器。

### 3.1 门控功能要求（必须由实际电路兑现）

输入定义：`ESTOP_OK`、`PWR_OK`、`WD_OK`、`OUTPUT_FEEDBACK_OK`；四者任一为 0，异步清除 `ARM_LATCH`。`MCU_ARM_REQ` 不是安全许可本身。

| 状态 | ARM_LATCH | 输出硬件许可 | 转换要求 |
|---|---:|---:|---|
| 刚上电/复位/下载 | 0 | 0 | 所有使能默认无效 |
| 急停按下/断线/监督失效 | 强制 0 | 0 | 无须 MCU 指令即可关闭 |
| 急停松开/电源恢复 | 保持 0 | 0 | 不因旧的高电平请求自动恢复 |
| 人工确认后重新请求 | 可置 1 | 仅条件全满足为 1 | 必须先看到请求回到 0，再接受新的有效边沿 |
| 任一执行器反馈异常 | 清 0 | 0 | 排故和重新确认后才能恢复 |

本表是安全逻辑规范，不是获认证安全电路。未核验监督器、逻辑门、锁存器的实体脚号和掉电行为前，不允许用普通 AND 门直接连接急停与一个保持高电平的 MCU 输出作为最终实现。简单 AND 会在松开急停时自动恢复，不能通过检查。

独立看门狗的喂狗必须来自经过主控制链健康检查的心跳；自由运行定时器/DMA 自动翻转 GPIO 不能证明应用仍工作。监督器掉电、断线、输出高阻均应使许可失效。硬件再使能按钮/人工确认路径要防粘连，不能短接作为生产默认。

### 3.2 各轴的落地记录

| 受控对象 | 必须填写的厂家证据 | 默认设计动作 |
|---|---|---|
| DRIVE_FL/FR | 驱动器 A 两通道安全输入、抱闸、反馈及故障作用范围 | 两通道都失能；按风险制动/驻车 |
| DRIVE_RL/RR | 驱动器 B 两通道同上 | 同上 |
| STEER_FL/FR/RL/RR | DM-J10010L 手册未证明硬件失能/STO/抱闸；需动力接触器及辅助反馈、通信失联实测和失电机械行为 | 先发厂家失能/零目标（命令取得后），再按批准时序切断两条转向动力支路；四轴均不得自动恢复 |
| 上盖推杆 | 内置限位、机械保持、防夹/掉落风险 | 硬件禁能；必要时机械支撑 |
| SM60E 电磁锁 | 通电生磁、断电消磁；双白反馈只确认“无磁”含义待测，不能证明门体贴合 | 本基线失电消磁；盖板防坠/人员保护由机械结构承担 |

外部驱动器的 12V/24V Enable 不能直接接 3.3V GPIO；根据输入类型使用隔离/开漏/继电器接口，确认源型/漏型、输入电流和断线状态。隔离必须同时考虑电源和回流，不能只画一个光耦符号。

## 4. BCM 输出策略的硬件边界

正常关机：上位机完成关机确认后再关闭 K1，超时策略另行定义。急停/硬故障优先安全，允许打断正常关机过程，但必须把数据丢失风险写入上位机设计。

急停时 K1、K3～K8、锁和推杆关闭；K2 仅保留独立允许的保护散热。若保留此功能，K2 的散热门控必须与被急停切断的公共线圈电源分开；不能八个继电器共用一条被切断的线圈电源又声称 K2 可工作。

K2 在 MCU 复位时默认关闭，与“传感器故障时软件强制开风扇”不是一回事。若热风险不允许 MCU 故障导致风扇停止，须增加独立温控器/热保护供电路径；在没有该硬件前不得宣称故障仍保证散热。

8 路继电器的触点可能焊死。切断线圈只能保证去激励，不能保证负载实际断电。任何安全关键负载必须增加具有反馈的独立串联断开通道或使用适合其风险的安全器件。
