# 通用原理图电路

本文提供可录入的连接清单和条件。V 表示脚功能已据存档资料核验；器件组合仍属 D 设计建议。所有物料封装以完整订货号为准，禁止只凭芯片简称复制网络库。

## 1. 原理图录入与符号规范

1. 先画电源页、MCU 最小系统和接口页，再画负载。先放实体焊盘号，后填网络名。
2. 多单元符号中的所有电源单元必须显式显示；禁止隐藏电源脚自动连网。
3. `NC`、`DNC`、`DNP` 含义不同：无内部连接、禁止外接、不装器件。不得相互替代。
4. 位号分别在 VCU/BCM 板内唯一；网络在各板局部定义；跨板必须通过连接器逐线确认。
5. 所有 H 项用“禁止放行”标注，不能为了清除 ERC 报错随意接地。

## 2. TPSM53603 Buck 单元（V：S03）

候选完整订货号：TPSM53603RDAR，RDA 15 焊盘 B3QFN 模块；内含电感，输入范围 3.8～36V，但推荐最低 VIN 取 3.8V 与 VOUT+1V 中较大者；输出 1～7V、最大 3A。5V→3V3 满足名义压差不代表极限欠压也满足。任何 12V 端实际浪涌必须经前级处理，不以 36V 作为可持续浪涌吸收能力。

| 实体焊盘 | 名称 | 连线与邻近器件 |
|---|---|---|
| 1、14 | VIN | 同接受保护输入；每个功率入口回路短；输入电容到 15 |
| 2 | EN | 本参考直接接该单元输入电源；不可悬空；需要 UVLO/关断另算分压 |
| 3、10、11 | NC | 厂家建议接 PGND 铜面以改善屏蔽与散热 |
| 4、5 | DNC | 各自独立焊盘，不接地、不相连、不连接其它网络 |
| 6 | PGOOD | 本参考不使用：仅留测试点、无上拉、不接 MCU；专用监督器负责电源监控 |
| 7、8 | VOUT | 全部相连到该输出轨；输出电容靠近，回到 PGND |
| 9 | FB | 10.0k 上电阻到输出采样点；下电阻到 AGND |
| 12 | AGND | FB 下电阻安静回流；按厂家布局在单点连到 PGND |
| 13 | V5V | 内部 LDO；本参考不带外部负载，不当作系统 5V |
| 15 | PGND | 功率底焊盘，必须焊接，连接输入/输出电容回路与散热过孔 |

| 目标轨 | R 上/下（建议 0.1%） | 标称输出计算 | 最小有效输出电容 |
|---|---|---:|---:|
| 5V | 10.0k / 2.49k | 5.016V | 28µF |
| 3V3 | 10.0k / 4.32k | 3.315V | 43µF |
| 4V0 | 10.0k / 3.32k | 4.012V | 35µF |

计算：Vout = 1V × (1 + R上/R下)。还须叠加芯片参考误差和电阻误差，不能把标称值当作上下限。

每单元输入：2×10µF/50V X7R 陶瓷，候选 Murata GRM32ER71H106KA12L（资料表 7-2 列出），或有完整偏压曲线证明的等效件；贴近 VIN 增加 100nF；负载阶跃场合预留 47µF/50V 非陶瓷储能。输入至少 20µF 陶瓷的要求不能仅用大电解代替。

每单元输出起始方案：2×47µF/10V X7R + 100nF，候选 Murata GRM32ER71A476KE15L（资料表 7-3 列出），必须补齐该型号的 DC 偏压/温度/容差曲线证明有效电容满足上表。两颗“47µF”在偏压下不一定仍有 94µF；不足时增加或换大封装。总输出电容不超过手册的稳定范围（推荐上限 1000µF），阶跃与启动实测后冻结。

若以后使用 PGOOD，不可直接从任意常电 3V3 拉高。手册规定该脚电压不得高于其 VIN+0.3V，必须校验启动、输入断电而输出电容仍有电、另一轨供电等所有时序，并加入适配/隔离；未满足前保持 NC。PGOOD 也不能替代独立硬件安全监督器。

模块布局严格按资料第 10 章：输入高 di/dt 回路最短，FB 远离功率回路，底焊盘散热过孔与厂家板厂工艺一致。不能复制本页电阻值却忽略参考布局。3A 是器件额定上限，不是密封外壳内任意 PCB 的连续保证。

## 3. CAN 单元（V：S04）

选择 TCAN1044AVDRQ1，带 VIO 的 TCAN1044AV-Q1，SOIC-8（D），该订货号在存档资料包装表列出；没有 V 的型号其第 5 脚为 NC，不能替代本单元。原理图值字段必须显式含 AV；采购时仍核当前生命周期、渠道和包装。

| 脚 | 名称 | 本设计网络 |
|---:|---|---|
| 1 | TXD | MCU FDCANx_TX；33Ω 串阻预留；10k 上拉到 3V3_LOGIC |
| 2 | GND | 本地逻辑地 |
| 3 | VCC | 5V_LOGIC；就近 100nF + 1µF 到地 |
| 4 | RXD | MCU FDCANx_RX；仅输入，不与另一个输出相连 |
| 5 | VIO | 3V3_LOGIC；就近 100nF |
| 6 | CANL | 保护后的该总线 L |
| 7 | CANH | 保护后的该总线 H |
| 8 | STB | MCU CANx_STB；10k 上拉到 VIO，复位默认待机；拉低正常工作 |

SOIC 没有 VSON 的底焊盘，不复制另一封装的 EP。STB 高为低功耗待机；唤醒通过 RXD 指示总线活动，不存在额外的 WK/INH 引脚。需要 CAN 唤醒时，5V VCC 与 3V3 VIO 必须保持有效，RXD 所接 MCU 管脚在选择的低功耗模式中确实可唤醒；否则只能使用“运行/浅睡眠”而不能承诺深睡眠唤醒。

BCM 的 U301.4 RXD 除接 PD0/FDCAN1_RX，还经 0Ω 配置位扇出到 PC12/EXTI12（只作输入），提供独立唤醒检测，10k 上拉到 VIO。不能将 PD0 再映射 EXTI0，因为 PB0 急停状态已使用 EXTI0。PCB 保留此路径，实际低功耗模式的 EXTI 唤醒仍须按 MCU 手册和台架测试确认；浅睡眠以外不作未验证承诺。

连接顺序：连接器 → 接口 TVS → 共模电感可选位 → 收发器；确保 TVS 回流短，不穿过 MCU 区。TVS 工作电压/电容/钳位必须同时满足合法 CAN 共模和收发器耐受值；其完整型号尚未核验，不以普通 5V 单向 TVS 代替 CAN 专用保护。

每条总线只装两端终端。各板预留 120Ω、1%、0.5W 可配置终端，默认 DNP 并在拓扑图写明谁装。断电全网 CANH–CANL 约 60Ω；单独只有一个终端的板约 120Ω；无终端板不应显示 60Ω。板上 H/L 长度与拓扑按选定波特率评估，不能以“都接上能收到”代替波形测试。

预留共模电感不等于必须装；首样可以配 0Ω 直通替位，但只能二选一，不能同时装导致错误短路。屏蔽接机壳的策略与信号参考地分开记录。

## 4. MCU 最小系统（D，GPIO 位置见附录）

| 网络 | 连接规则 | 未关闭条件 |
|---|---|---|
| VDD | 所有 VDD 接 3V3_LOGIC；每脚就近 100nF，区域 4.7µF | MCU 电气手册、启动峰值、布局复核 |
| VSS/VSSA | 全部连接地；模拟回流远离电机回流，不割裂数字参考平面 | VDDA/VREF 实际手册核对 |
| VDDA | 3V3 经 0Ω 配置位到 VDDA，近脚 100nF + 1µF | 模拟精度需要时改滤波并校核压降/时序 |
| VBAT | 不装后备电池时接 3V3，近脚 100nF | 禁止同时硬并电池和 3V3 |
| VREF | BCM 提议接 VDDA，近脚去耦；VCU 43/44 脚暂 H | 不猜测 VREF_+ 含义；确认内部参考缓冲设置 |
| NRST | 外部开漏监督复位、10k 上拉、100nF 到地、测试点 | NRST 保持复位功能；不得改作普通 PG10 |
| PB8-BOOT0 | 10k 下拉；壳内测试焊盘 | 启动选项与系统 Bootloader 能力需验证 |
| PA13/PA14 | SWDIO/SWCLK，分别保留测试点与近地 | 不复用为负载控制 |
| PB3 | SWO 可选测试点 | VCU CAN3 不占用该脚 |
| PF0/PF1 | 预留 HSE 晶体和负载电容位，DNP 值待选晶体 | CAN 精度要求下必须冻结频率、CL、ESR、启动裕量 |
| PC14/PC15 | LSE 可选，不用则 NC 标识 | 不默认宣称 RTC 长期精度 |

HSE 可评估 8MHz 晶体，但本包未验证具体晶体/CL，不可照抄“22pF”。负载公式 CL≈C1×C2/(C1+C2)+Cstray；用实际寄生与厂家要求计算，并测试最低电压/最高温度起振。若改有源时钟，只接其输出到 OSC_IN、OSC_OUT 按手册处理，不能同时装晶体方案。

下载夹具提供 VTREF（只采样）、SWDIO、SWCLK、NRST、GND 和防呆定位。不得通过下载器 VTREF 反向给整板供电。关机板仍连接 USB/CAN/UART 时要验证反灌。

本包没定义 MCU 外接 VCAP。不能把其它 STM32 型号的 VCAP 接法复制到这里；按具体芯片电源引脚表设计。

## 5. 电压采样参考单元（D）

用于 12V 输入和 K1 输出的起始值：上电阻 100k、下电阻 10k（1%，上电阻可拆成 2×49.9k），分压点并 10nF 到安静地，再经 4.7k 到 ADC。12/11=1.091V，24/11=2.182V；下支路开路、输入过压和 MCU 断电均需另查故障。

不能仅加钳位到 3V3 就结束设计：钳位电流可能抬高关机电源轨。实际输入钳位/隔离缓冲必须校核 MCU 注入电流、ADC 源阻抗和 3V3 反灌；未取得该 MCU 电气手册前该项为 H。4.7k 和 10nF 会改变采样建立时间，要使用足够长采样窗口。

K1 输出电压存在时说明该节点有电，不能单独证明继电器机械触点状态；外部设备也可能反灌。关断判定需有负载放电路径/时间并同时检查上游电源与外部反灌。

## 6. 干接点与外部数字量

干接点“无源”指外部不提供电源。板端施加限流检测电流是必要的，不等于给锁线圈供电。设计要求：单独 `SENSE` 与 `SENSE_RETURN`、输入保护、滤波、施密特整形；根据触点规定的最小润湿电流选择检测电流。

短板内干接点可从 3V3 经 2.2k 限流作为初始试验，闭合约 1.5mA；此值不保证任何外部锁触点可靠。车载长线/可能误接 12V 时必须用有故障耐压的输入前端，不能直接把此分压示例引出连接器。急停前端的硬件通道不能因消抖算法而延迟安全动作。

SM60E 规格图只把两根白线称为“无磁信号反馈”，没有确认它是干接点；在万用表和限流源辨识之前，不得直接套用本节 2.2k 上拉，更不得向其施加 12V。即使确认是触点，也只能按厂家/实测定义解释有磁状态，不能据此证明机械贴合或可靠锁定。

外部 WAKE 基线定义为以 UART_REF/公共参考地为参考的有效高 12V 输入，经隔离或车载输入调理得到 3V3；最终输入阈值、漏电、断线状态与所接开关确认后冻结。不得把未知 12V 线接到普通 GPIO。35P 只剩一个唤醒位置，不支持独立两线浮地唤醒而不调整接口。
