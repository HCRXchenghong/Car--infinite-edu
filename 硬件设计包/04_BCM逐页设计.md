# BCM 逐页设计

## 1. 页面与电源分配

| 页面 | 位号 | 主要内容 |
|---|---|---|
| B01 | J_BCM_EXT、输入保护 | 单 35P 接口、电源汇流、源端和板内保护 |
| B02 | U201/U202/U203 | 12V→5V、5V→3V3、12V→4V0 |
| B03 | U101 | STM32G491VET6、复位、时钟、SWD、完整脚表 |
| B04 | U301/U302 | CAN1 主干、CAN2 扩展 |
| B05 | K1～K8、Q901～Q908 | 继电器触点、线圈驱动和每路保护 |
| B06 | U701 | 电磁锁智能高边、诊断与独立干接点 |
| B07 | U401 | MC33926、推杆电机、故障/电流检测 |
| B08 | U501 | EG800Z-GL 常电、SIM、RF、串口电平与时序 |
| B09 | U601/U602 | 两个 SHT31、短 I2C、地址与传感窗口 |
| B10 | U801～U803 | 监督、看门狗、安全锁存、外部输入与唤醒 |
| B11 | 所有 TP/连接器 | 整板测试与线束物理映射 |

4V0 给 4G 独立供电，不由 K1 控制。TPSM53603 的 4V0 方案仅在模块实际电压范围与最坏峰值/热条件允许时成立；≥3A 是目标，不是已确认 EG800Z-GL 的电气要求。如果峰值/启动超过供电能力则换更高电流器件，不能把模块峰值写小。

4G、CAN 唤醒和 MCU 的必要电源保留常电；深睡眠方案未闭合时先采用运行/浅睡眠基线，不宣称 PSM/eDRX 或超低静态电流。PSM 可能使远程下行不可达，不能同时承诺随时远程唤醒。

## 3. 八路继电器的可复用单元

负载路径：`12V_PROT → F_Kx → Kx.COM → Kx.NO → Kx_OUT`；NC 触点不用并标 NC。保险放在触点前，按 DC 分断能力/浪涌/线束配合选择。K1 外部设备集合仍是一个负载组，需要每个设备的启动/持续电流证据。

线圈路径：`12V_COIL_x → 线圈 → Qx.D；Qx.S→PGND`。逻辑门输出经 100Ω 到 MOS 栅极，47k 栅源下拉。候选 MOS 必须在 VGS=2.5/3.3V 有 RDS(on) 保证、耐压和 SOA 足够；只写“阈值低”不构成选型。端子脚号按所选继电器/晶体管手册补齐，不能把 COM/NO 的逻辑名当实体 1/2 脚。

线圈续流二极管阴极接线圈 +12V，阳极接 Q.D。二极管电流/反向耐压覆盖线圈最大值。普通二极管会延长继电器释放时间；如果停止时间不满足，按器件耐压选择二极管+齐纳/TVS 等快速退磁方案并测释放时间，不直接拔掉续流器件。

K1、K3～K8 的栅极驱动必须被 BCM_HW_PERMIT 硬件门控；K2 按独立散热策略处理。MCU 复位/下载时所有线圈去激励。供电域切断不应通过 GPIO/续流路径反向供电。

负载端若是风扇、灯内 DC/DC 或其它感性/容性负载，必须由负载侧数据选择抑制器件与预充/限流。线圈续流只保护线圈驱动 MOS，不能保护触点所切换的外部负载。

K1 输出接独立电压检测，实际器件对输入反灌的路径也要检查。每路 2A 是负载设计目标，不是“装 2A 保险必定可用”的结论。

## 4. 电磁锁单元

路径：`12V_PROT → F_LOCK → 智能高边 VS；OUT → LOCK_PWR_OUT → 锁 → LOCK_RETURN → PGND`。驱动器要求：支持实际 12V 范围、约 1A 连续目标与真实浪涌、感性关断能力、短路限流/过温、默认关闭、可读诊断、与 3V3 逻辑匹配。5A 是预留能力，不是允许锁无限堵转/短路到 5A。

高边 EN = 锁请求与硬件许可的有效组合；失电开锁、急停关闭。若需要把电流诊断送 PA3，必须使用具体型号规定的比例/电阻和限幅，不能复制 MC33926 的 FB 参数。智能高边器件及实体封装尚未选定，B06 功率器件部分为 H。

两根锁状态线与两根功率线分开。干接点前端施加小检测电流，核对触点润湿电流和“锁到位闭合”的定义；断线、短线和真实未到位在简单双线输入中并不都可区分。需要区分时增加末端电阻检测方案及诊断阈值，不宣称普通 GPIO 有断短线诊断能力。

## 5. MC33926 实体连线（V：S02，32 引脚 PQFN+EP）

本存档 Rev.10.0 手册对应 MC33926PNB，卷带为 MC33926PNBR2；封装为 8×8mm、32 引脚 PQFN，封装图号 98ARL10579D。不得使用 HSOP footprint，也不能把手册底视图直接当顶视焊盘序。当前生命周期与供货还须核验。

| 脚 | 名称 | 连线要求 |
|---|---|---|
| 1 / 2 | IN2 / IN1 | 经可关断、掉电安全的逻辑缓冲；各 2.2k 下拉作为初始设计 |
| 3 | SLEW | 接地，首样采用慢边沿；更改前看损耗与 EMI |
| 4、6、11、31 | VPWR | 全部接受保护 12V_ACT，宽铜；就近储能/去耦 |
| 5、EP | AGND | 与 PGND 极低阻连接；EP 必须焊接，不能悬空 |
| 7 | INV | 接地，采用不反相真值表 |
| 8 | FB | 150Ω/1%/0.25W 到安静地；并 1nF 起始滤波；经保护/串阻到 ADC |
| 9、17、25 | NC | 无连接，标记 NC |
| 10 | EN | 2.2k 下拉；有效高请求，经硬件许可与缓冲 |
| 12、13、14、15 | OUT1 | 全部相连宽铜到 ACT_OUT1，不可只接一脚 |
| 16 | D2 | 2.2k 下拉；低为禁止；硬件许可失效必须低 |
| 18、19、20、22、23、24 | PGND | 全部接功率地回路，避免经模拟地细线 |
| 21 | SF | 开漏；15k 上拉到 3V3，接经保护的 MCU 输入 |
| 26 | D1 | 高为禁止；上电/复位默认高；2.2k 上拉为有电默认，掉电另验证 |
| 27、28、29、30 | OUT2 | 全部相连宽铜到 ACT_OUT2 |
| 32 | CCP | 33nF/50V 陶瓷到 VPWR，不是到地；允许 30～100nF |

VPWR 近端初始配置：100nF/50V + 10µF/50V 陶瓷 + 470µF/35V 低 ESR 储能；容量、纹波电流、温度和回灌电压必须实测。板上最弱器件的安全电压决定浪涌保护，不能看到 MC33926 短时耐受 40V 就允许其它 12V 器件到 40V。

输入内部拉电流典型 80µA、手册测试上限 200µA。100k 下拉会失效；10k×200µA=2V 也不能确保小于 1V 的低电平。2.2k×200µA=0.44V 才有初始裕量，还需计入漏电和输出能力。外部缓冲要求有掉电高阻/Ioff、耐受电源顺序且默认关闭；不能只依赖 MCU 内部弱拉。

VPWR 有电而 3V3 无电时，内部拉流可能经 MCU/外部上拉反灌。必须核验缓冲、D1 上拉和 3V3 泄放/反灌，不可将这张逻辑表当作已完成电源顺序验证。EN 与 D2 的硬件低电平禁止必须在该故障下保持。

SF 上拉 15k 时最大约 3.3/15000=0.22mA，低于资料 0.3mA 测试电流；4.7k 会到 0.70mA，超过其允许 <0.5mA，禁止采用。

FB 不是电压输出：在 6A 时手册给最大 17.15mA，150Ω 得 2.573V（未加电阻容差）。高于 6A 的精度不能外推，内部限流可能到 8A 且并非线束保护；ADC 仍要有故障限幅和关机反灌处理。低电流零点/比例误差大，不应用单个“精确比例”推断堵转，需实测标定。FB 主要反映高边电流，续流期间与平均电机电流不同。

### 5.1 真值与停机

以下 INV=0，H/L 为实际芯片脚电平。

| 模式 | EN | D1 | D2 | IN1/IN2 | OUT1/OUT2 |
|---|---:|---:|---:|---|---|
| 正向 | H | L | H | H/L | 高/低 |
| 反向 | H | L | H | L/H | 低/高 |
| 两端低续流/制动状态 | H | L | H | L/L | 低/低 |
| 两端高续流状态 | H | L | H | H/H | 高/高 |
| D1 硬件禁止 | H | H | 任意 | 任意 | Z/Z |
| D2 硬件禁止 | H | 任意 | L | 任意 | Z/Z |
| 睡眠 | L | 任意 | 任意 | 任意 | Z/Z |

Z/Z 是功率管关闭，不等于机械抱闸。两端低也不等于可以无限期安全制动。推杆实际 OPEN/CLOSE 必须空载测方向并贴标，不能仅依据电线颜色。反转先禁止、等待电流衰减后换向；过流/超时/故障不自动反向。

芯片欠压恢复会自动恢复原输出状态，不能仅靠其内部 UVLO 达成“不自动重启”；外部硬件锁存必须清除许可。短路/过温故障需要控制输入等动作清除，禁止盲目周期重试。SF 在禁止状态也可能低，不能把所有 SF=0 都解释为独立短路故障。

优先选带内置方向限位、机械自锁/保持说明的两线推杆；内置限位是否能允许反向退出也要核验。若需要两路外置限位，当前 35P 只有一个备用位，不够，必须调整接口。堵转电流和软件超时不是防夹安全功能。测试盖板必须有机械支撑，禁止用身体测试防夹。

## 7. SHT31 与外部输入

U601 地址 0x44，U602 地址 0x45（7 位地址，不能误写成移位后的 0x88/0x8A）。需核实具体 SHT31 变体封装和 ADDR 接法。每个传感器 100nF 近端去耦，I2C 总线仅一组上拉，起始 4.7k 到 3V3，按实际电容/上升沿调整，首样 100kHz。

两个传感器按默认假设位于 BCM 板/同壳短线区域。U601 靠通风采样窗口并远离热源，U602 测板区；若真实舱内位置远离板区，必须另做传感子板/线束定义并重新分配 35P，不能把板上温度称为舱内真实温度。传感开口不涂三防漆、不清洗液浸泡、不被胶封住。

急停输入使用独立辅助触点或隔离安全状态，绝不并接加载 VCU 主急停。WAKE 的输入调理、锁干接点与 UART 保护按通用页面，实际电平与外设手册确认。

## 8. 必备测试点

12V_RAW/PROT、5V、3V3、4V0（模块近端）、NRST、SWD、两路 CAN、每个继电器请求/栅极/触点后端、K1 ADC、锁 OUT/FAULT/ADC、MC33926 EN/D1/D2/IN1/IN2/FB/SF/CCP/VPWR、急停调理前后、HW_PERMIT、WD、SHT SCL/SDA、4G 控制/串口/维护接口。

MC33926 OUT1/OUT2、CCP 必须用适合共模的差分探头；接地示波器地夹不接到 H 桥输出或 CCP。普通地夹只接确认的本地地，否则会短路功率级。
