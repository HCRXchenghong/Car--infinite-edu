# 连接器、线束与机械装配

## 1. 必须先确认观察方向

逻辑槽位 `B01～B35` 仅用于分配数量，不是 K776280WV 厂家腔号。不得按 B01=1 的方式出压接工单。数据附录“厂家腔号”保持 H，待受控图纸和样件连续性确认后填写。

每个正式连接器图同时给出：板端器件顶视图、板端插合面、线束端插合面、线束端出线面；标注锁扣方向、1 号腔标记、公母定义、板端与对插件号。插合面与出线面可能镜像，不能用“从左到右”作定义。

正式线束图必须包含端子/密封塞/空腔堵头/二次锁型号、导线外径范围、剥线长度、导体压接高度、绝缘压接高度、拉脱力和所用模具。以上数值直接使用端子厂家表，不用一组通用数值套全部端子。

## 3. VCU 逻辑端口

| 标识 | 逻辑内容 | 注意事项 |
|---|---|---|
| J_PWR | 12V_IN / PWR_RETURN | 主电源端子按 3A 连续/5A 峰值和热降额选，不用未验证 3A 小信号座 |
| J_CAN1 | CAN1_H/L/REF | 主干；终端位置随拓扑冻结 |
| J_CAN2 | CAN2_H/L/REF | 四台 DM-J10010L-2EC，经典 CAN 1Mbps；电机端只有 H/L，REF/接地或隔离策略 H；不带动力 |
| J_DRIVE_A/B | CAN3_H/L/REF；ENABLE、QUICK_STOP、FAULT、READY、RESET、IO_RETURN | 逻辑共 9 路/口，电平/数量随厂家双通道接口调整，不是实体针图 |

DM-J10010L-2EC 每台有两个 CAN 端口和两个 XT30 电源端口。CAN2 优先按 `VCU → 电机1 → 电机2 → 电机3 → 电机4` 的线性链路布置，VCU 与最远端电机各一个 120Ω，所有中间电机关闭 CAN 终端拨码；实际轴顺序按最短主干和可维护性冻结，不用逻辑 FL/FR/RL/RR 强迫形成星形支线。四台电机的动力不经过 J_CAN2 或 VCU PCB，按系统电源章节分为每支路最多两台的独立保护/接触器支路。

厂家附件的 GH1.25-2pin/3pin 与 XT30 可用于台架，但正式车载线束仍需确认配套件完整料号、锁止、线径、耐温、防水、防错插和振动固定。不能仅凭“GH1.25”或“XT30”名称制作生产压接表；调试 UART 也不作为车外常驻接口。
| J_ESTOP | ESTOP_LOOP_SEND / RETURN | 常闭回路，独立安全前端 |
| J_REARM | REARM_SENSE / RETURN | 人工重新武装按钮；防粘连和新边沿要求 |
| J_STEER_SAFE | STEER_PERMIT / FEEDBACK / IO_RETURN 等 | 最终 STO 双通道或接触器接口 H；不得用 3 根线假定满足所有方案 |
| J_BMS | VCU_TX / VCU_RX / BMS_REF | 确认隔离和电平；不默认提供 BMS 电源 |
| J_US1～8 | PWR_SW / RETURN / VCU_TX / VCU_RX | 电压/物理层未确认前不定实体针 |
| J_TOF1～4 | 同上 | 与超声波外形相同但电气不同则用不同键位 |
| RF | 模块 U.FL 至密封穿墙件 | 同轴弯曲半径、拉力和天线位置按厂商要求 |

具体连接器针数以最终信号数量与隔离电源需求决定。外部 24V 安全输入可能需要额外回路/双通道，不可压缩为一个普通 Enable。

## 4. 线径与配线原则

线径按载流、压降、温度、束内降额、端子压接范围和机械强度共同确定。候选起始评估：2A 负载短线 0.5mm²、BCM 四根并联输入各 1.0mm²、VCU 主线 1.0mm²、信号 0.22～0.35mm²；这些是计算起点，不是已批准裁线工单。若所选端子不接纳该线径，优先更换端子体系或重新设计，禁止削细铜丝塞端子。

每根线表必须填：线号、起点器件/物理腔号、终点器件/腔号、网络、电平、线径、绝缘等级、颜色、成品长度、公差、双绞/屏蔽、端子型号和检查结果。线色只是辅助，不能替代线号与连续性检查。

电机线/12V 大电流线与 CAN、UART、传感器线分束；相交尽量近直角。CAN 成对绞合并尽量保持到端子附近；不将 CAN_H 与地配成一对。屏蔽在图纸指定点连接机壳，不能临场多点搭接。

线束有应力释放、固定点和活动部位余量；不让拉力传给焊盘/U.FL。导线远离运动夹点和锐边，加护套/护线环。锁扣、二次锁与密封塞全部到位后才验证防水。

## 5. 台面装配顺序

1. 独立核对连接器样件与 PCB footprint；先做 1:1 打印和实物贴合，再签机械确认。
2. 使用正确模具压接试样，测高度和拉脱力；每批首件、换线径/模具后重新确认。禁止锡焊加固替代合格汽车端子压接。
3. 按线号裁线、套标、压接、装密封件、插腔、轻拉确认锁止、装二次锁、封堵空腔。
4. 线束单独 100% 通断检查：每根到正确腔，无相邻短路；与母板实际插合再次确认极性。未连接电子设备前进行所要求的绝缘测试，禁止对已接 MCU 板使用兆欧表。
5. 安装 PCB 的绝缘/接地柱与垫片；确认螺钉不会触碰铜面和背面器件，扭矩按紧固件/结构图。板框、孔位和最大器件高度未定前，不切正式外壳。
6. 先连接参考地/电源回路并断电验线，再连低压信号，最后按台架试验流程接负载；禁止带电试插未知接口。
7. 盖板推杆固定后用机械支撑承重，验证全行程不顶死、不拉线、不碰 PCB，再进行低能量方向试验。
8. 保留维修余量与标签，盖壳前拍摄端子腔位、保险位、板号、线束号和地汇流点，归档。
