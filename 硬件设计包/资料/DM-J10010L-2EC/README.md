## 项目可采用的资料结论

- 型号为 `DM-J10010L-2EC`，电机和驱动器一体化、减速比 10:1、双磁编码器，输出轴提供单圈绝对位置。
- 手册称额定 48V、支持 24～48V；额定相电流 23.5A、峰值相电流 95A；额定扭矩 40N·m、峰值扭矩 120N·m；额定转速 100rpm@48V。
- CAN 为 11 位标准帧，默认 1Mbps。支持 MIT、位置速度、速度、力位混控模式；参数访问和控制帧格式见手册。
- 两个电源接口和两个 CAN 接口用于走线/菊链；CAN 120Ω 终端由拨码 4 控制。手册建议电源串接走线不超过 2 台，本项目不得把四台电机全部串接在一个未经校核的电源支路。
- 保护包括驱动过温、电机过温、过压、欠压、过流和通信丢失退出使能，但门限/超时含可配置项，不能在未读回实际参数时假定默认值安全。

## 仍属待确认或资料矛盾

- 本目录没有可编译的软件例程；README 只是资料发布说明。厂家手册引用的《调试助手使用说明书（达妙驱动控制协议）V1.4》未随包提供。
- 手册没有给出完整的上电使能、失能、清故障和安全停机命令，也没有证明存在硬件 Enable、STO 或抱闸输入。
- `TIMEOUT` 寄存器没有给出单位、默认值和零值语义；通信丢失保护必须经正式协议和抓包/断线实测确认。
- 反馈帧把 D0 写成 `ID | ERR<<4`，同时又称 ID 为 CAN_ID 低 8 位；一个字节无法无冲突地同时承载完整 8 位 ID 和高 4 位状态。不得在厂家澄清前自行假定 ID 位宽。
- 手册提示切换位置控制前读取寄存器 `0x50`，而寄存器表中 80/`0x50` 为电机位置、81/`0x51` 才是输出轴位置；需要确认用于无冲击切换的真实量。
- 力位混控段写最大电流 99.74A，参数表写峰值相电流 95A；项目限流不得以较大的冲突值为依据。
- 24～48V 是资料支持范围，不等于可直接接任何“48V 电池”。电池满充、回生抬升和瞬态必须低于经厂家确认的允许值；58.8V 不在 24～48V 标称支持范围内。
- 未给出 DC 母线连续/峰值输入电流、连接器/线规额定、IP 等级、工作温度、轴向/径向载荷、回差、回驱/失电保持和寿命数据。
