## 4. 评审与关闭工作流

收到输入 → 核对型号/版本 → 更新候选物料与连接页 → 用具体数据重算 → 更新 Pinmap/接口图 → 独立复核 → 重建 PDF/DOCX → CAD ERC/DRC → 样板验证。任何影响腔号/电压/极性的变更都升级硬件/线束版本并作旧版停用说明。

只有纸面文件完整不能证明实际样板可靠。下一步应是依据本包完成有 H 标识的原理图草图，并关闭 H01～H16；不能直接把本包交板厂要求投板。

## 5. 重建与自检

1. 使用带 reportlab、python-docx、pypdf 的 Python 依次运行 `工具/generate_data.py`、`工具/generate_connections.py`，产生数据表、附录和逐焊盘连接册。
2. 运行 `工具/build_print.py` 生成主手册 PDF/DOCX，再运行 `工具/build_workbook.py` 生成完整横向作业册，最后运行 `工具/verify_package.py`。
3. 查看数据校验与导出报告；人工抽查封面、正文密集表、228 脚附录和最后签字表，确认没有截字/缺页。
4. 改 GPIO 必须改工具中的单一分配源，并同步相应正文概要；改电路需更新相关计算、BOM、测试和变更日志。

工具不会验证外部器件电平、保护协调、真实 CAD 连接和硬件性能。生成通过只表示文档内部的有限检查通过。
