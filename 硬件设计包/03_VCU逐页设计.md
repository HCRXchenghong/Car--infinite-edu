# VCU 逐页设计

## 1. 页面清单与电源树

| 页面 | 主要位号 | 需要完成的网络 |
|---|---|---|
| V01 输入/保护 | J_PWR、F101、输入保护单元 | 12V_RAW、12V_PROT、GND、输入检测 |
| V02 电源 | U201/U202/U203 | 5V_LOGIC、3V3_LOGIC、5V_SENSOR_RAW |
| V03 MCU | U101 | 附录 128 脚表、复位、时钟、SWD、采样 |
| V04 CAN | U301/U302/U303 | CAN1_MAIN、CAN2_STEER、CAN3_DRIVE |
| V05 UART 扩展 | U401/U402/U403 | SPI1、3 组 CS/IRQ/RST、12 路 UART |
| V06 传感器端口 | U710～U721、J_US1～8/J_TOF1～4 | 各端口电源保护、电平/物理层、回流 |
| V07 BMS/无线 | J_BMS、U501 | USART2、SPI4、RF_IRQ/RESET/SWD |
| V08 安全 | U601～U603 与安全接口 | 监督、锁存、八轴禁能、反馈、再使能 |
| V09 连接器/测试 | 所有连接器与 TP | 逻辑接口与物理针脚对照、测试点 |

U201：12V_PROT→5V_LOGIC；U202：5V_LOGIC→3V3_LOGIC；U203：12V_PROT→5V_SENSOR_RAW。三者按通用 Buck 单元连接。3V3 逻辑预算目标 1A；传感器轨初步按 2.4A 连续、3A 峰值评估，超过则升级电源/散热，不将 3A 长期满载视为已经验证。

12V 输入 3A 连续/5A 短时是接口设计目标，不是推荐直接装 5A 保险。保险时间电流曲线、端子能力和线束保护按实测启动波形确定。

## 3. MAX14830 单元（V：S01，TQFN48+EP）

候选完整订货号 MAX14830ETM+，封装代码 T4877+3，资料第 67 页列出。每一行适用于 U401、U402、U403，不能只接一颗完整供电后复制遗漏。3V3 逻辑与 UART 侧均采用 3.3V；5V 传感器电平另转换。

| 脚 | 名称 | 接法 |
|---|---|---|
| 1 | SPI/I2C | 接 3V3，选择 SPI |
| 2 | LDOEN | 接 3V3，启用内部 1.8V LDO |
| 3 / 4 / 6 | MISO/SCLK/MOSI | 共用 SPI1；SCLK/MOSI 源端 22～33Ω 可调串阻 |
| 5 | CS | 该片独立 CS、10k 上拉；三路不可并联 |
| 7 | IRQ | 开漏低有效，该片 EXTI 输入、10k 上拉 |
| 8 | RST | 该片独立复位、10k 下拉；自检前保持低 |
| 9 | VL | 3V3、100nF 到 DGND |
| 10 | DGND | 地平面 |
| 43 | VEXT | 3V3、100nF 到 DGND；这是 UART/GPIO 接口电源，不能漏 |
| 44 / 45 | XOUT/XIN | 每片独立晶体；见时钟条件 |
| 46 | AGND | 安静地并低阻接板地 |
| 47 | VA | 3V3、100nF 到 AGND |
| 48 | V18 | 内部 1.8V 输出；1µF 到 DGND；不得接 3V3 |
| EP | 暴露焊盘 | 接 AGND 并焊接；不能用 EP 代替 46 脚连接 |

| 通道 | RX 输入脚 | TX 输出脚 | RTS / CTS 脚 | GPIO 脚 |
|---:|---:|---:|---|---|
| 0 | 17 | 18 | 15 / 16 | 11～14 |
| 1 | 25 | 26 | 23 / 24 | 19～22 |
| 2 | 33 | 34 | 31 / 32 | 27～30 |
| 3 | 41 | 42 | 39 / 40 | 35～38 |

未使用 RTS 为输出，NC；不使用硬件流控时 CTS 经 10k 到地并在配置中关闭流控；未用 GPIO 作为输入并固定到可确定的空闲态/内部设置，不能任意与电源硬短接后又配置输出。

时钟：每片候选 1.8432MHz 晶体（处于允许 1～4MHz 内），内部 XIN/XOUT 各有典型 16pF 负载电容；晶体 CL≈8pF+板寄生，必须选匹配晶体并验证 ESR/启动。外部负载电容位默认 DNP，不能再随手装两颗 22pF。亦可改外部有源时钟，允许输入范围 0.5～35MHz，XOUT 悬空并切换配置，但不可两种方案同时装。

SPI 使用 MODE0（CPOL=0、CPHA=0），最高 26MHz 只是芯片能力。首样从 8MHz 验证；3 颗器件并挂的电容、线长、MISO 三态和取样边沿都要用示波器看。128-word FIFO 不是无限缓冲：115200bit/s、8N1 时 128 字节约 11.1ms 填满；波特率越高允许服务延迟越短。

## 4. 十二个端口的唯一映射

| 芯片/通道 | 设备 | 接口 | 电源保护 |
|---|---|---|---|
| U401 CH0～3 | USONIC_1～4 | J_US1～J_US4 | U710～U713；SENS_EN_A / FAULT_A |
| U402 CH0～3 | USONIC_5～8 | J_US5～J_US8 | U714～U717；SENS_EN_B / FAULT_B |
| U403 CH0～3 | TOF_1～4 | J_TOF1～J_TOF4 | U718～U721；SENS_EN_C / FAULT_C |

每个端口逻辑信号：`PWR_SW`、`RETURN`、`VCU_TX→SENSOR_RX`、`VCU_RX←SENSOR_TX`。这四个名称不是已确认物理针号。TX/RX 从 VCU 方向命名；接线表再写对端名称，不按线色猜方向。

每端口有独立限流/关断开关；四路 EN 可同组控制，只有真正开漏兼容的故障信号才允许线与。每路支路短路不能把其它支路或逻辑电源拖掉。候选电流预算 0.2A/路是规划值，不是传感器规格；限流值需高于正常浪涌且低于线束/端子安全值。

UART 选择树：3.3V TTL 短线 → 保护后连接；5V TTL → 双向各一条固定方向电平转换并核验断电隔离；RS-232 → 专用正负电压收发器；RS-485 → 差分收发器且确认传感器协议。RS-485 不能只在 VCU 一端加芯片就兼容原来的 TTL 设备。长线强干扰优先使用两端匹配的差分方案。

传感器电源关闭时，TX 高电平不能经传感器保护二极管继续供电；使用带 Ioff/禁能的缓冲和正确电源时序。所有外部口考虑 ESD、误接电源和插拔；未确认传感器型号前电平转换与外部腔号均 H。

## 5. BMS、无线与 CAN 拓扑

BMS 使用 USART2 独立端口，不与 MAX 共用。不假定 BMS UART 是安全的 3.3V TTL 或其“GND”与 VCU 直接同地；需核验是否位于电池高侧、是否隔离、最大共模和供电方式。未确认前不连线通电。

nRF52840 使用 SPI4 作为建议主机链路，实际模块必须暴露这些 IO 并配套固件。模块需独立 SWD/复位/恢复路径；RESET 若与普通 GPIO 复用必须配置验证。优先模块本体带 U.FL，不再在载板制作第二套 RF 匹配。模块供电近端 100nF+10µF 为起始值，按供应商峰值/布局补齐。无线停机请求不等于经认证急停。

CAN1 拓扑由整车线束确定，上位机/BCM/VCU 串接在主干短支路，不用三条任意长支线星形连接。CAN2 接四个转向器，CAN3 接两台 MSSD-100EMA_2EC_N 驱动器。若保留 J_DRIVE_A/B 两个出口，将 VCU 位于 CAN3 主干中间、A/B 位于两端，则 VCU 不装终端，A/B 各装一端；若改菊链，重新标定终端位置。不能既在 VCU 装终端又默认每台驱动器装终端。

### 5.1 CAN3 的实际协议边界（V：S07/S08）

MSSD-2EC 协议明确使用 CAN 2.0A 的 11 位标准数据帧，不支持扩展帧和远程帧，资料同时明确写出“暂不支持 CANopen”。它借用了 CANopen SDO 风格的命令字、对象索引和中止码，但这不等于实现 CiA 301/CiA 402；不得假设存在 NMT、PDO、SYNC、EMCY、标准 Heartbeat 或 EDS。

默认波特率为 500kbps、默认节点 ID 为 1。两台驱动器装车前必须分别设置并记录唯一节点 ID，否则同一请求会产生冲突应答；建议分配值只在联调表批准后写入，不在 PCB 丝印中硬编码。协议允许 10kbps～1Mbps、节点 1～127，节点 0 为广播；最终速率和广播使用规则由系统协议冻结。

普通请求使用节点 ID 作为 11 位标识符，8 字节数据载荷采用 SDO-like 命令：0x2F/0x2B/0x27/0x23 写 1/2/3/4 字节，0x40 读取。Modbus 寄存器 0x0000～0x0FFF 映射到索引 0x4000+寄存器地址，子索引为 0。现有 S08 的启动/停止/读取示例可用于制作台架向量，但完整寄存器定义引用另一份尚未取得的 RS485 手册，不能仅凭示例完成四轴控制。

商户口述支持电机状态主动上报，现有 S08 未给出该功能的标识符、使能寄存器、触发/周期、载荷、缩放、字节序和丢包规则。取得正式定义前只能轮询已知寄存器，不能把主动上报写进冻结协议。S08 的两字节应答示例还出现 0x42，而同页状态码表列出 0x4B，必须向厂家确认并用抓包实测，解析器不得悄悄同时接受所有冲突值而不报警。

通信中断、错误帧或驱动器复位不能仅靠“最后一次目标仍为零”保证安全。必须把厂家通信超时保护、外部开关量停机/抱闸接口、总电源接触器以及 VCU 独立硬件许可组合成实际安全链；CAN 停止寄存器不等于 STO。

## 6. 本板测试点与交接

至少保留：12V_RAW/PROT、5V_LOGIC、3V3_LOGIC、5V_SENSOR_RAW、每组传感器输出、三片 V18、NRST、三组 IRQ/CS、SPI1 时钟、3 路 CAN TXD/RXD/H/L/STB、WD 心跳、ESTOP_OK、ARM_LATCH、HW_PERMIT、各驱动器禁能与反馈、BMS TX/RX、无线 SWD/复位及邻近 GND。

每个安全测试点应有夹具可接的 GND 和可辨认标签，不能让测试时探针滑动短接 12V 到 GPIO。原理图交接必须附“所有 GPIO 为高阻、MCU 未烧录”的状态检查结果；不能等代码写好后才发现默认使能。
