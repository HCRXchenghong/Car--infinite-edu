# 电源、保护与热设计计算

所有算例为 D：明确假设下的预算，不是实际电流。必须用供应商数据和实测波形替换，保留原始示波器文件、环境温度、供电值、负载状态和测量点。

## 1. VCU 逐级预算示例

假设 3V3 总电流 1A，两个转换级效率各 85%，CAN 三路合计按 5V/0.3A 预算，传感器总计 5V/2.4A。

| 计算项 | 公式 | 结果 |
|---|---|---:|
| 3V3 输出功率 | 3.3×1 | 3.30W |
| 3V3 从 5V 取电 | 3.3/(5×0.85) | 0.776A |
| 5V_LOGIC 总电流 | 0.776+0.300 | 1.076A |
| 逻辑链 12V 输入功率 | 5×1.076/0.85 | 6.33W |
| 传感器链输入功率 | 5×2.4/0.85 | 14.12W |
| 12V 总输入电流 | (6.33+14.12)/12 | 1.70A |
| 假设降到 9V 的输入电流 | (6.33+14.12)/9 | 2.27A |

尚未包括保护损耗、监控和温度影响。3V3 的 1A 已包含 MCU/MAX/无线等总预算，不能又把同样负载在 5V 表重复计算；也不能完全漏掉上游 5V 为 3V3 供电的电流。

传感器若达 3A，输入功率约 23.98W，9V 时约 2.66A，仍需增加其它损耗/降额；U203 已满 3A 没有连续电流余量。电源短路隔离还需 F_VCU、输入限流与分支限流时序配合。

## 2. BCM 15A 目标尚未闭合

假设每个 K 通道都达到其 2A 目标，锁 1A、推杆 1A、每只继电器线圈 70mA、4G 为 4V/3A、其它逻辑输出功率 4.05W、转换效率 85%。

| 负载 | 12V 等效电流 |
|---|---:|
| 8 路触点负载 | 16.00A |
| 锁 + 推杆 | 2.00A |
| 8 只线圈 | 0.56A |
| 4G 峰值预算 | 1.18A |
| 其余逻辑预算 | 0.40A |
| 合计 | 20.13A |

这已超过 15A 连续目标，也略高于原 20A 短时目标；持续时间和真实同时工况未知，因此不能把原方案标成通过。实际负载不一定同时满载，但任何依赖限制组合的方案必须说明硬件防过载措施，不能靠“平时应该不会同时开”。

K1 2A×12V=24W，包含上位机、功放、屏、摄像头与路由器，是否足够必须逐设备核算。若不够，升级 K1 全链或拆分；不可只换大保险。

外部 DCDC 同时还要供 VCU。选型需输入电池全范围、连续功率、峰值时间、温度降额、效率、隔离、输出短路、浪涌/过冲、反灌和 EMI 资料；没有这些不能给出唯一可靠型号。

## 3. 线束与端子

铜线近 20°C 的计算起点：R=0.0175×L/S，单位 Ω、m、mm²；高温电阻上升，近似乘 (1+0.00393×ΔT)。L 是完整去回路径长度。

例：单程 2m、2A、0.5mm²，两线总长 4m，R≈0.14Ω，压降 0.28V，损耗 0.56W；端子、保险、继电器、PCB 压降还要叠加。成束、密闭高温环境必须按线材厂家降额。

四针并联：额定 15A 平均 3.75A/针；单针断开平均 5A/剩余针；峰值 20A 单针断开平均 6.67A/剩余针。因不均流最热针可更高，“标称 7A”不足以直接证明通过。需要最坏相邻满载/老化/温度下的接触电阻和温升。

P接点=I²R接点。只量外壳温度不足，应看端子、压接、焊脚和附近塑胶温度；接受值由厂家最大温度和项目温升限值中更严者决定。

## 4. 保险/eFuse 与反接保护

每条保护路径记录：正常电流、启动峰值/时间、线材/端子耐受、保护额定与降额、分断能力、I²t、故障源最大电流、上游保护选择性。K1～K8 各一路、锁一路、推杆一路、板载电源支路、VCU 传感端口均不可遗漏。

选择原则：额定与降额不误断正常负载；故障切断在导线、器件、端子的热耐受之前；源短路电流不超过熔断器 DC 分断能力。PTC 的动作慢、温度敏感、持续故障会热，不能在无曲线验证下替代快速保护。

反接 MOS 按实际最大输入、RDS(on) 在实际栅压/最高温度下计算；15A、10mΩ 已耗散 2.25W，20A 时 4W。反接保护不一定阻止输出向输入回灌，需核验 MOS 方向/体二极管/双向阻断条件。大电容浪涌需要预充或受控限流，不能靠 MOS 雪崩长期承担。

TVS：正常最高电压 < VRWM；最坏脉冲电流下钳位加布局过冲 < 被保护器件允许值；能量、脉宽、重复率、温度降额全部验证。TVS 与保险应保证 TVS 短路失效能被安全切除。一个写着“SMBJ”的占位符不是已完成浪涌设计。

DCDC 输出侧不是原车 12V 铅酸电池端，适用瞬态波形必须根据真实 DCDC 和线束测量/试验规范确定，不能机械套用或宣称已符合汽车标准。

## 5. 推杆热与回灌

MC33926 在 150°C 条件单个导通 MOS 最大 225mΩ，电流经过高低两只，电阻损耗近似 I²×0.45Ω：1A 为 0.45W，3A 为 4.05W，5A 为 11.25W，另有开关等损耗。这解释了为什么“5A 峰值”绝非普通小铜皮上的 5A 连续能力。

结温：Tj≈Ta+P×有效热阻；有效热阻由封装、铜面、过孔、外壳和气流决定，不能直接把数据手册测试板数值当本板实测。内部过温关断是最后保护，不是正常温控。

电容吸收能量：ΔE=0.5×C×(Vmax²−V0²)。以 470µF、12V 升至 18V 为例，只能增加约 0.042J；实际盖板惯量/重力势能可能远大于此。必须测停止/反转电压并评估机械保持和能量路径，不把大电解当制动系统。

## 6. 4G 瞬态和电源完整性

阶跃所需电容粗估 C≥ΔI×Δt/ΔV，再加 ESR 瞬降 ΔV_ESR=ΔI×ESR。例：供电环路在 200µs 内少供 2A，允许掉 0.2V，需要约 2000µF；如果实际 Buck 响应更快则可能少很多。此算例说明不能无依据指定“470µF 一定够”，最终取决于模块脉冲和转换器响应。

在模块 VBAT 引脚处测，不在电源模块输出端代替测；使用短接地弹簧/差分测量，记录最差输入电压、弱信号发射、网络重连和同时启动负载。通过限值取模块允许供电范围与纹波要求。
