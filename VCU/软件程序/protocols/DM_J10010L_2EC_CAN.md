# DM-J10010L-2EC CAN 协议实现输入

状态：依据本项目存档的厂家《DM-J10010L-2EC 减速电机使用说明书 V1.1》整理；尚未抓包、未接实物、未形成可烧录驱动。冲突和缺项必须保留为错误，不得由代码静默猜测。

## 物理与节点基线

- 经典 CAN、11 位标准帧、默认 1Mbps；不发送 CAN FD、扩展帧或远程帧。
- 每台电机必须有唯一 `ESC_ID`（接收 ID）和唯一 `MST_ID`（反馈仲裁 ID）。四台同默认值并联会发生寻址/反馈冲突。
- CAN2_STEER 只承载四台转向电机和 VCU。线性/菊链拓扑仅在两个物理端安装 120Ω；电机拨码 4 为 CAN 终端，不能四台全开。
- 电机 CAN 端子只有两线，资料未提供独立参考地。非隔离 CAN 的地电位差、动力负极连接和断地故障必须由线束/隔离方案关闭。

## 参数访问

参数读请求：标准帧 ID `0x7FF`，D0～D1 为目标 CAN ID 低/高字节，D2=`0x33`，D3=寄存器地址，其余不关心。成功响应使用该电机 `MST_ID`，D2=`0x33`，D4～D7 为小端数据。

参数写请求：标准帧 ID `0x7FF`，D0～D1 为目标 CAN ID，D2=`0x55`，D3=寄存器地址，D4～D7 为小端数据；立即生效但掉电丢失。存储请求 D2=`0xAA`，成功响应前 4 字节为目标 ID、`0xAA`、`0x01`。存储寿命/忙时间未定义，不得周期写 Flash。

关键寄存器（地址为十进制）：

| 地址 | 名称 | 类型 | 用途/边界 |
|---:|---|---|---|
| 4/5 | ACC/DEC | float | 加减速度；DEC 范围为负值，单位未明确 |
| 6 | MAX_SPD | float | 最大速度；单位须实测/协议补充 |
| 7 | MST_ID | uint32 | 反馈仲裁 ID，四节点必须唯一 |
| 8 | ESC_ID | uint32 | 接收/控制 ID，四节点必须唯一 |
| 9 | TIMEOUT | uint32 | 通信超时；单位、默认值、0 的含义未给出 |
| 10 | CTRL_MODE | uint32 | 1 MIT、2 位置速度、3 速度、4 力位混控 |
| 21/22/23 | PMAX/VMAX/TMAX | float | MIT 反馈/命令线性映射范围；每台上电读回并做一致性检查 |
| 29 | OV_Value | float | 过压值；厂家表中范围仍为 TBD |
| 35 | can_br | uint32 | 0/1/2/3/4 = 125k/200k/250k/500k/1M |
| 80/81 | p_m/xout | float | 电机位置/输出轴位置；模式切换段对 0x50 的描述存在歧义 |

所有 `float` 暂按手册“小端”描述处理；是否为 IEEE-754 binary32 必须通过已知值读写和抓包确认后才冻结。

## 运动控制帧

| 模式 | 仲裁 ID | DLC | 载荷 |
|---|---:|---:|---|
| MIT | `ESC_ID` | 8 | P16、V12、Kp12、Kd12、T12 按位拼接；映射范围取 PMAX/VMAX/TMAX |
| 位置速度 | `0x100 + ESC_ID` | 8 | D0～D3 `p_des` float rad；D4～D7 `v_des` float rad/s；均小端 |
| 速度 | `0x200 + ESC_ID` | 4 | `v_des` float rad/s，小端 |
| 力位混控 | `0x300 + ESC_ID` | 8 | P float rad；V uint16/100 rad/s；I uint16/10000 标幺 |

首轮转向联调优先评估位置速度模式，但这只是工程建议。切换控制模式会清零位置、速度、前馈、KP/KD；必须在零速、已读回实际位置、机械悬空/限能条件下切换。MIT 位置控制的 Kd 不得为 0。

## 反馈帧

反馈使用 `MST_ID`：D0 为节点/状态复合字段，D1～D2 为 POS16，D3～D4 高半字节为 VEL12，D4 低半字节～D5 为 T12，D6/D7 为 MOS/线圈温度（℃）。POS、VEL、T 依 PMAX/VMAX/TMAX 线性解码。

状态码：0 失能、1 使能、8 超压、9 欠压、A 过流、B MOS 过温、C 线圈过温、D 通信丢失、E 过载。

D0 的 ID 位宽存在资料矛盾。在厂家正式协议/抓包确认前，解析器必须把不满足批准编码规则的 D0 记为协议故障，不得用“低 4 位大概是 ID”的猜测继续闭环控制。

## 四轴配置与安全要求

- `STEER_FL/FR/RL/RR` 的 ESC_ID、MST_ID、SN、固件版本、控制模式、TIMEOUT、PMAX/VMAX/TMAX、正方向、绝对零位和软限位逐台记录；不把轴位写死为某个出厂 ID。
- 配置 ID/波特率时一次只连接一台未配置电机，写入后存储、断电重启、读回，再接入公共总线。
- 单圈绝对编码器存在 2π 环绕。控制层使用连续角度前必须定义解包、机械限位、上电零位可信度和传感器跳变处理。
- 报文超时、状态非 1、温度/电流/位置越界、反馈 ID 重复或映射参数变化时，立即退出正常闭环并锁存故障。
- CAN 失能命令和通信超时只是补充动作。当前资料没有硬件 STO/Enable 证据；急停必须通过经验证的 DC 动力接触器/安全继电器切断四台转向电机支路，且监测接触器反馈。
- 实物联调前设置低速度、低限流/限矩和机械悬空；不得以 95A/99.74A 或 120N·m 作为首测指令。
