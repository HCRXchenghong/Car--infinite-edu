# VCU PCB 打板说明

当前逐页原理图输入、实体脚表和检验程序见 [HW-R1 硬件实施包](../../硬件设计包/00_使用说明与放行边界.md)。本文为制造准备说明，不能替代实际 CAD 和样板验证。

> 文档状态：审查修订说明 v0.3（存在阻断项，未达到 Gerber 放行条件）
> 适用对象：四轮四转机器人底盘教育版 VCU 控制板
> 配套总体设计：[VCU 教育版总体设计](../总体设计.md)

## 1. 文档目的

本文用于指导 VCU 控制板从总体架构进入原理图、PCB、打板、贴片和首件验证阶段。本文重点描述板内网络分区、三路 CAN、12 路 UART 扩展、2.4GHz 无线、安全链路、电源预算、130 mm × 90 mm 板框、调试接口和制造验收要求。

VCU 与 BCM 是两个独立、并行推进的模块。VCU PCB 应能够独立完成 MCU 下载、三路 CAN 基础测试、无线模块测试、传感器串口测试和安全输入验证；不能把 BCM 在线作为 VCU 首件上电或调试的前置条件。

本文不替代 VCU 总体架构设计。达妙转向电机、CANopen 驱动器、BMS、超声波、ToF 和上位机/BCM 的厂家协议与最终接口资料到位后，才冻结具体帧格式、波特率、节点 ID、连接器针脚和部分电气参数。

## 2. 当前板级基线

### 2.1 主控和通信资源

| 功能 | 已确定方案 | PCB 要求 |
|---|---|---|
| MCU | STM32G474QET6TR，Cortex-M4F，170MHz，LQFP128 | 最小系统、SWD、NRST、BOOT 和维护测试点完整 |
| CAN-1 | FDCAN1，上位机/BCM 主干 CAN FD | 独立收发器、保护、终端配置和连接器 |
| CAN-2 | FDCAN2，4 个达妙转向关节电机，CAN/CAN FD 待厂家协议确认 | 独立收发器、保护、终端配置和接口 |
| CAN-3 | FDCAN3，两台一拖二驱动器的经典 CAN/CANopen | 独立收发器、保护、终端配置和接口 |
| UART 扩展 | MAX14830 × 3 | 共 12 路扩展 UART，共享 SPI、独立片选和中断 |
| BMS | MCU 原生 UART，独占 | 不得与传感器或调试串口复用 |
| 无线 | 待选定的带 U.FL/IPEX 外置天线座 nRF52840 模块 | 必须定义 nRF 固件/主机协议，并保留 nRF 独立 SWD；板边布置、50Ω 天线走线、射频禁布区 |
| 安全 | 教育验证用两线常闭本地急停 + 八轴硬件安全门控 | 不得只接普通 GPIO；四个驱动轴和四个转向轴都必须进入安全态 |
| 看门狗 | IWDG 为主、WWDG 为辅，预留外部硬件看门狗 | 监督输出参与 SAFETY_ENABLE |

### 2.2 车载接口实现约束

VCU 的电源、CAN1/2/3、驱动器安全信号、两线常闭急停、BMS、超声波和 ToF 等正式对外车载线束接口，统一使用带锁止、防水和防呆结构的汽车连接器。UART 是通信协议，不是连接器类型；BMS 和传感器 UART 不得使用 2.54mm 4 芯 UART 母头作为正式车载接口。VCU 首版按 12V 输入 3A 连续、5A 短时峰值校核，四个驱动轮和四个转向执行器的动力电源不经过 VCU PCB。

嘉立创商城已查到可作为 CAN/UART/急停等小信号接口候选的 `DL20023`/`JWPF` 方向型号，例如 `DL20023-2AS`、`DL20023-3AS`、`DL20023-4AS`，2 mm 间距、IPX7、页面常见额定约 3A。它们不用于 VCU 主 12V 输入；主电源连接器应按至少 5A 和启动瞬态另行选型。各接口的针数、端子规格、板端/线束端配对、线径、额定电流、空腔堵头和防护等级随原理图、线束图及外壳设计冻结。SWD、串口日志和生产测试只通过密封外壳内的测试焊盘、测试夹具或临时维护接口访问。nRF52840 的 U.FL/IPEX 仅用于板内 50Ω 射频同轴连接，外置天线通过密封射频穿墙件出壳。

### 2.3 节点和轴的板级对应

VCU PCB 不直接把运动学逻辑写进某一个电机接口。板内应按统一逻辑名称标识通道，具体物理插座在原理图和线束图确认后再冻结。

```text
转向轴：STEER_FL / STEER_FR / STEER_RL / STEER_RR
驱动轴：DRIVE_FL / DRIVE_FR / DRIVE_RL / DRIVE_RR
传感器：USONIC_1 ~ USONIC_8 / TOF_1 ~ TOF_4
CAN：CAN1_MAIN / CAN2_STEER / CAN3_DRIVE
```

两台一拖二驱动器在控制逻辑中必须视为四个独立驱动轴，但物理 CAN-3 只有一条总线。驱动器通道与车轮的映射应保存在参数表或线束配置中，不应通过 PCB 走线名称隐式决定。

## 3. 打板前的设计输入

Gerber 发布前必须收齐或明确标记以下输入：

1. STM32G474QET6TR、MAX14830、nRF52840 模块、CAN 收发器及电源器件的最终封装；其中三颗 MAX14830 还要明确晶振/外部参考时钟方案、`VL/VEXT/VA/V18` 电源、`RST` 默认态、开漏 `IRQ` 上拉和带宽预算；
2. 三路 CAN 的收发器型号、供电电压、待机/使能逻辑和总线保护方案；
3. 达妙电机协议及 CAN-2 的速率、节点 ID 和终端位置；
4. 两台驱动器的 CANopen 接口电平、节点模型、NMT/心跳/PDO 配置和安全信号电气定义；
5. BMS UART 的电平、波特率、接口方向，以及防水汽车连接器的针脚定义；
6. 8 路超声波和 4 路 ToF 的 UART 电平、波特率、线长和是否需要 RS-485/电平转换；
7. nRF52840 模块的供电峰值、射频布局、U.FL/IPEX 座和天线型号；
8. 实际 12V 输入瞬态、外部保护、各逻辑电源电压和板内功耗预算复核；
9. PCB 外形、安装孔、散热、防水汽车连接器朝向和外壳空间；
10. 本地急停、驱动器 Enable、Quick Stop/Brake、Fault、Ready、Reset 的实际有效电平。
11. STM32 完整 Pinmap、复用冲突、默认电平、DMA/中断资源和时钟树；
12. 四个转向执行器的硬件 Enable/STO，或切断其动力的安全接触器方案及反馈；
13. 上位机/无线遥控器的唯一控制权仲裁、无线武装和死手逻辑；
14. nRF52840 具体模块、独立固件、STM32↔nRF 主从协议和双 MCU 升级/恢复方案。

未收齐的协议不应被“猜测值”写死在 PCB 丝印、不可替换电阻或单一连接器定义中。可以先使用可配置终端、跳帽、测试点和预留电阻完成样板兼容性。

## 4. 原理图分区

VCU 原理图建议按以下功能页组织，网络命名和 PCB 区域保持一致。

### 4.1 输入电源和电源树

VCU 首版外部输入为 12V，按 3A 连续、5A 短时峰值设计。原理图应先明确输入保护和板内电源域：

- 输入反接、浪涌、TVS 和滤波；
- MCU/数字逻辑电源；
- CAN 收发器电源；
- MAX14830 和传感器接口电源；
- nRF52840 干净 3.3V 射频电源；
- 必要的模拟采样电源和 ADC 参考；
- 每个电源域的测试点、复位监控和上电时序。

板内功率预算按以下目标执行：5V 外部传感器电源能力 2～3A，3.3V 逻辑/射频电源能力 0.8～1A。即使最终部分传感器由独立电源供电，也保留 3A/5A 的输入余量，避免连接器、反接保护和 DCDC 因降额而导致首件不可用。

HW-R1 采用独立 12V→5V_SENSOR_RAW Buck，再经每端口限流/关断输出，三组使能并提供故障反馈；逻辑使用 5V_LOGIC→3.3V_LOGIC。仍需源端保护协调，不得让传感器短路经共用 12V 源拖垮 MCU/CAN/硬件门控。原理图放行前用分析和台架证明故障隔离。

5V→3.3V 在接近 1A 时优先采用 Buck。若使用 LDO，必须提交最坏压差、电流、环境温度和 PCB 散热条件下的结温证明。

电源域必须在原理图中显式命名，不允许通过“同名但不同电压”的模糊网络连接 MCU、CAN 收发器和射频模块。

### 4.2 MCU 最小系统

STM32G474 区域包含：

- 所有电源脚的就近去耦；
- VDDA/VSSA 的模拟电源处理；
- NRST、BOOT、SWDIO、SWCLK、必要的 SWO/串口日志测试焊盘；不设置对外 4 芯 UART 母头；
- 3 路 FDCAN 引脚；
- SPI 主接口及 3 个 MAX14830 片选；
- 3 个 MAX14830 的独立中断输入；
- BMS 原生 UART；
- 具体 nRF52840 模块确认后的主机接口、IRQ、RESET，以及 nRF 独立 SWD/量产测试接口；
- 急停状态、SAFETY_ENABLE 监测和驱动器安全信号；
- IWDG/WWDG 和外部监督器心跳。

MCU 引脚分配要形成独立的 Pinmap 文件或表格，标出复用功能、方向、默认电平、上拉/下拉、是否安全相关和是否需要测试点。

### 4.3 三路 CAN

每一路 CAN 均独立包含：

- MCU FDCAN 接口；
- CAN FD 收发器；
- 收发器待机/使能控制；
- CANH/CANL 的 TVS 或等效保护；
- 共模电感预留位；
- 120Ω 终端电阻配置位；
- 接口 ESD 保护和信号测试点；
- 清晰的总线编号、方向和电气标识。

三路 CAN 是彼此独立的物理网络，PCB 不应在保护器件、终端电阻或连接器处把 CAN1、CAN2、CAN3 误并联。

### 4.4 MAX14830 UART 扩展

三颗 MAX14830 通过 SPI 连接 MCU：

```text
SPI_UART：SCK / MOSI / MISO
MAX14830_A：CS_A + IRQ_A → USONIC_1 ~ USONIC_4
MAX14830_B：CS_B + IRQ_B → USONIC_5 ~ USONIC_8
MAX14830_C：CS_C + IRQ_C → TOF_1 ~ TOF_4
```

每颗 MAX14830 应有独立片选和中断，通道标识要贯穿原理图、PCB 丝印、连接器、线束和软件设备抽象层。所有外部 UART 输入输出通过防水汽车连接器进入线束，并根据传感器电平和线长配置保护、电平转换、串联电阻或 RS-485 预留；不使用对外 4 芯 UART 母头。

每颗 MAX14830 必须包含经过核对的晶振或外部参考时钟、`VL/VEXT/VA/V18` 电源与去耦、`RST` 默认态和开漏 `IRQ` 上拉。HW-R1 给出每片独立晶体建议；内部已有负载电容，外部电容不能随手按其它芯片复制。若改共享时钟，核对扇出、边沿、stub 和启动顺序；不能只完成 SPI/CS/IRQ 连线就放行。

### 4.5 无线模块

nRF52840 模块至少需要：

```text
SPI_SCK / SPI_MOSI / SPI_MISO / RF_CS
RF_IRQ / RF_RESET / RF_ENABLE
3.3V_RF / GND
模块本体 U.FL/IPEX 天线接口，或经参考设计验证的载板 RF 接口（二选一）
```

上述 SPI/IRQ/ENABLE 仅在具体模块和自研 nRF 固件确认采用该接口后成立。nRF52840 是独立可编程 SoC，必须为其保留 SWD、复位和版本兼容/升级恢复路径，不能把未定义的“无线模块协议”直接画死在 PCB 上。

射频电源与数字逻辑电源的关系要在原理图中明确。若模块已有板载射频匹配和稳压，VCU PCB 不得重复加入未经确认的匹配网络或射频滤波。

### 4.6 本地急停和安全门控

本地急停使用两线常闭回路：

```text
VCU_ESTOP_NC+ ── 外部急停按钮常闭触点 ── VCU_ESTOP_NC-
```

急停回路必须同时进入独立硬件安全链路和 MCU 状态输入。硬件安全链路至少应对两台驱动器的 Enable 产生直接影响，并预留：

```text
DRIVE_A_ENABLE / DRIVE_B_ENABLE
DRIVE_A_QUICK_STOP / DRIVE_B_QUICK_STOP
DRIVE_A_FAULT / DRIVE_B_FAULT
DRIVE_A_READY / DRIVE_B_READY
DRIVE_A_RESET / DRIVE_B_RESET
SAFETY_ENABLE
```

硬件安全链路还必须覆盖四个转向执行器。若转向电机没有硬件 Enable/STO，则应设计由安全门控控制、带反馈的动力接触器/安全继电器，或更换具备安全输入的执行器方案。只能通过 CAN 发停止命令时，不满足当前急停目标。

单通道两线常闭回路仅作为受控、低速、有人监护的教育验证基线；涉及人员保护时，必须依据风险评估升级为双通道安全回路和反馈监控。

实际高低电平、开漏/推挽、上拉电压和隔离要求必须根据驱动器手册确认。CANopen Quick Stop、目标速度归零或软件禁能不能成为唯一急停路径。

## 5. PCB 层叠和区域规划

### 5.1 推荐层叠

VCU 含三路 CAN（CAN-1 为 CAN FD，CAN-2 模式待厂家协议确认，CAN-3 为经典 CAN/CANopen）、SPI 扩展、12 路 UART、射频和安全逻辑，推荐优先使用 4 层或更多层板，以保证连续地平面和可控回流：

| 层 | 建议用途 |
|---|---|
| L1 | MCU、收发器、MAX14830、关键短线和器件连接 |
| L2 | 连续 GND 平面，保持高速/射频回流连续 |
| L3 | 逻辑、CAN、射频等电源平面或分区电源铜 |
| L4 | 低速 I/O、维护信号、补充电源和接口引出 |

最终层数、铜厚、板厚、介质厚度和阻抗以板厂能力、输入功耗、接口速率和机械约束校核后冻结。CAN、SPI 和射频区域不能因层叠变化而失去连续参考平面。

### 5.2 物理分区

建议将板面分为五个区域：

1. 电源入口与电源转换区；
2. MCU、调试和安全状态机区；
3. 三路 CAN 收发器与外部总线区；
4. MAX14830 与传感器接口区；
5. nRF52840、U.FL/IPEX 和射频天线区。

电源开关节点、CAN 保护器件、传感器长线接口和射频区域应有明确边界。电机线束、驱动器高噪声线束和外部电源入口尽量从板边进入并快速离开噪声敏感区。

### 5.3 板框与机械可行性

VCU 首版板框目标为 **130 mm × 90 mm**。相较 120 mm × 80 mm，面积增加约 22%，但在真实连接器、安全门控/接触器接口、nRF52840 模块、安装孔和外壳 3D 模型导入前，不得作出“基本可行、余量适中”的冻结结论。布局必须满足：

- 电源入口和三路 CAN/驱动器接口沿板边布置；
- 三颗 MAX14830 靠近传感器接口，避免 12 路 UART 长距离穿越噪声区；
- nRF52840 与 U.FL/IPEX 保留完整射频禁布区；
- 130 mm × 90 mm 内预留安装孔、连接器插拔空间、线束弯曲半径和外壳筋位间隙；
- 最终投板前使用实际封装做 3D 干涉和散热核对。

## 6. 关键布局要求

### 6.1 MCU 和时钟

- STM32G474 的去耦电容靠近对应电源脚，回路短而直接；
- 晶振、时钟和 NRST 远离 CAN 收发器、DC/DC 开关节点和长线接口；
- SWD 测试焊盘靠近板边并保留探针空间，不作为对外线束接口；
- BOOT、NRST、状态 LED 和维护按键便于样板调试；
- 看门狗/监督器放在能够同时观察 MCU 心跳和安全门控的位置。

### 6.2 CAN 收发器

三颗 CAN 收发器分别靠近对应连接器，CANH/CANL 从收发器到保护器件再到连接器尽量短、直、成对。终端电阻靠近总线端点并可配置，不要让 CAN 差分线绕过 MCU 或穿过电源开关节点。

CAN1、CAN2、CAN3 的连接器和丝印应有明显差异，防止整车接线时误插。若三路连接器外形相同，应增加机械防呆或颜色/标签区分。

### 6.3 MAX14830 和 UART 接口

MAX14830 靠近传感器连接器集中布置，SPI 主线尽量短，三路片选和中断线避免长距离平行。12 路 UART 若跨越电机、电池和驱动器区域，应在接口侧预留 ESD、串阻、电平转换或 RS-485 子板的兼容位置。

BMS 原生 UART 独立靠近 MCU 和专用连接器，不应从 MAX14830 旁路或与普通传感器接口共用收发器。

### 6.4 射频和 U.FL/IPEX

- nRF52840 模块放在 PCB 边缘；
- 优先使用模块本体自带的 U.FL/IPEX，此时载板不再走 2.4GHz 射频线；
- 只有模块提供 RF 引脚并要求载板连接 U.FL/IPEX 时，才按参考设计做 50Ω、匹配和连续地平面；
- 模块下方、天线走线两侧和连接器周边遵守模块/天线厂商禁布要求；
- 射频区域远离 CAN 收发器、电源开关节点、晶振、继电器和电机接口；
- 不在射频走线下方随意切割地平面或穿越电源分割缝；
- 若使用外置天线，机械固定和同轴线弯折半径应在装配图中说明。

### 6.5 安全链路

急停输入、SAFETY_ENABLE、驱动器 Enable 和 Quick Stop/Brake 相关器件应集中布置，减少普通软件信号绕行。安全信号旁边设置清晰测试点，允许在不上电机的情况下验证：正常闭合、急停断开、MCU 复位、外部监督器超时和驱动器故障时的输出状态。

安全链路上的上拉、下拉、晶体管、继电器或隔离器件不得被普通功能复用。凡是会影响电机使能的网络，都要在原理图和 PCB 上使用统一的 `SAFETY_` 或 `DRIVE_` 前缀。

## 7. 布线要求

### 7.1 CAN 差分线（兼容 CAN FD）

- CANH/CANL 保持相邻和连续参考平面；
- 控制差分线长度、线宽、间距和分支，避免长 stub；
- TVS 和共模电感按收发器/连接器顺序布局，器件回流路径短；
- 终端电阻使用跳帽、拨码或可替换电阻配置；
- 总线保护地回流不能穿过 MCU 或射频地的敏感区域；
- 三路总线分别标识，不共享未经确认的终端和保护器件。

CAN-1 的 CAN FD 数据段速率，以及 CAN-2 是否使用 CAN FD，待协议冻结后以收发器和板厂阻抗能力为准；CAN-3 按经典 CAN/CANopen 要求配置。

### 7.2 SPI 和中断

SPI 连接 3 颗 MAX14830。SCK、MOSI、MISO 和片选线尽量短，必要时预留源端串联电阻位置用于抑制振铃。每颗 MAX14830 的 IRQ 独立回到 MCU，不用软件轮询替代中断线。

SPI 走线不要穿过 CAN 电源开关节点或射频天线区域。MAX14830 的逻辑电源去耦应靠近器件，外部传感器线的噪声不应直接回灌 SPI/MCU 地。

### 7.3 UART 和长线接口

逻辑电平 UART 不等于车载远距离物理层。每类传感器的电平、波特率、最大线长、供电和保护必须在 Gerber 前冻结。线长较长、共模噪声较大或传感器电源不稳定时，优先使用 RS-485/CAN 或本地汇聚子板；只预留 0Ω、电阻或 TVS 不能替代物理层选型和验证。

### 7.4 电源和地

- MCU、CAN、MAX14830、BMS 和射频电源分别标识并按负载回路布置；
- `5V_SENSOR` 与 `3.3V_LOGIC` 具有明确故障隔离，每个传感器分组的限流开关、故障反馈和测试点靠近接口；
- 射频 3.3V 通过独立滤波或低噪声供电方案获得，最终参数待模块确认；
- 大电流输入/驱动器信号回流不应经过 MCU、ADC 或射频区域；
- 电源开关节点面积最小，反馈线远离电感和开关管；
- 所有外部接口附近提供地参考和必要的 ESD 泄放路径；
- 地平面尽量连续，只有在电源或安全隔离有明确依据时才做分区。

## 8. 连接器、丝印和测试点

除射频和测试点外，以下所有 `J_` 接口均为防水汽车连接器。逻辑名称统一如下，最终接口编号由原理图和线束图共同冻结：

```text
J_PWR          VCU 板电源输入
J_CAN1_MAIN    上位机/BCM 主干 CAN FD
J_CAN2_STEER   4 个达妙转向电机总线，CAN/CAN FD 待确认
J_DRIVE_A      CAN3 + 驱动器 A 安全信号；驱动器动力电源不经 VCU 板
J_DRIVE_B      CAN3 + 驱动器 B 安全信号；驱动器动力电源不经 VCU 板
J_ESTOP        两线常闭本地急停
J_BMS          BMS 独立 UART
J_USONIC       8 路超声波接口
J_TOF          4 路 ToF 接口
RF_UFL         nRF52840 板内 U.FL/IPEX 射频同轴接口，连接密封射频穿墙件
TP_DEBUG       SWD、NRST、BOOT 和 GND 测试焊盘，不作为对外线束接口
TP_TEST        关键电源、心跳和安全状态测试点
```

`CAN3_DRIVE` 是一条逻辑总线，通过 `J_DRIVE_A/J_DRIVE_B` 接到两台驱动器；默认不再增加第三个外部 CAN3 插座，以免形成未校核的支线。两个连接器的布线顺序、stub 长度、线束终端位置和屏蔽/参考地必须在 CAN 拓扑图中冻结。

丝印至少应包含接口编号、针脚 1、电源极性、`CANH/CANL`、`GND`、总线名称、传感器通道、急停状态和板卡版本。对于相同外形的 CAN/传感器防水汽车连接器，应使用机械防呆、不同颜色或明显文字区分。

测试点至少包括：

- 输入电源和各逻辑电源；
- MCU 复位、BOOT、IWDG/外部监督器心跳；
- CAN1/2/3 的 CANH/CANL；
- SPI_SCK/MOSI/MISO、CS_A/B/C 和 IRQ_A/B/C；
- BMS UART；
- `ESTOP_ACTIVE`、`SAFETY_ENABLE`；
- 两台驱动器 Enable、Quick Stop/Brake、Fault、Ready、Reset；
- 四个转向轴的安全使能/STO，或安全接触器控制和反馈；
- nRF52840 独立 SWD、复位、IRQ 和经模块确认的主机接口关键线。

## 9. EMC、ESD 和可靠性设计

### 9.1 外部接口

所有正式对外车载接口使用防水汽车连接器，并根据线长和环境增加 ESD/浪涌保护。保护器件应靠近连接器，泄放路径短，不能让瞬态电流经过 MCU 或 nRF52840 模块下方。连接器、端子、线束护套、空腔堵头和壳体出线共同满足目标防护等级；仅有 PCB 三防或仅有连接器胶圈均不能代表整机防水。

### 9.2 CAN 和驱动器环境

CAN 接口应预留 TVS、共模电感和终端配置。驱动器相关的安全信号和 CAN 线束应与电机动力线分区，连接器处应明确屏蔽层/地线策略，最终以整车线束和实测 EMI 结果调整。

### 9.3 射频共存

2.4GHz 射频区要避免数字高速线、开关电源、CAN 共模电感和长线接口靠近。nRF52840 的供电纹波和地回路应通过实测确认，不能仅凭逻辑电源额定电压判断无线链路可靠性。

## 10. 制造和装配要求

### 10.1 板厂询价包

发给板厂的文件应明确：

- PCB 层数、板材、板厚和铜厚；
- 最小线宽/线距、最小孔径、阻焊和字符能力；
- 有无阻抗控制，控制哪些网络；
- 表面处理、工艺边、定位孔和拼板方式；
- 连接器、模块、插件件是否贴装；
- U.FL/IPEX、MAX14830、CAN 收发器和安全器件的装配要求；
- 清洗、三防、灌封和禁涂区域；
- 首件是否提供 AOI、X-Ray、飞针或电气测试报告。

### 10.2 BOM 和封装核对

- `STM32G474QET6TR` 的 LQFP128 封装、焊盘和 1 脚方向核对；
- MAX14830 的封装、SPI/IRQ、参考时钟、VL/VEXT/VA/V18、RST、开漏 IRQ 上拉和去耦要求核对；
- CAN 收发器的 FD 兼容性、供电电压和待机引脚逻辑核对；
- nRF52840 模块、模块自带 U.FL/IPEX（或经参考设计验证的载板 RF 路径）和天线保持正确机械方向；
- 防水汽车连接器的额定电流、线径、锁止、防呆、空腔堵头、插拔方向和壳体干涉核对；
- 安全链路器件不允许使用未经确认的替代料；
- 0Ω、终端电阻、共模电感、ESD 和电平转换预留件在 BOM 中明确装/不装状态。

## 11. 首件上电和调试顺序

### 11.1 上电前检查

1. 目检板框、安装孔、接口方向和器件极性；
2. 检查输入保护和电源域之间无短路；
3. 检查 MCU、MAX14830、CAN 收发器和无线模块的焊接质量；
4. 检查三路 CAN 终端配置和保护器件装配；
5. 检查急停回路、安全门控和驱动器接口的默认状态；
6. 测量各电源域对地阻值，记录未上电基线。

### 11.2 分阶段上电

```text
限流电源、断开外部驱动器
        ↓
验证输入保护和各电源域
        ↓
SWD 下载、复位、BOOT 和看门狗
        ↓
验证 CAN1/CAN2/CAN3 收发与终端
        ↓
验证 SPI + MAX14830 + 12 路 UART
        ↓
验证 BMS UART
        ↓
验证 nRF52840 SPI、IRQ、复位、使能和射频
        ↓
验证急停、安全门控和故障输入
        ↓
接入驱动器，先不连接机械负载
        ↓
最后进行四轮四转联调
```

首件测试不得一开始就连接电机动力线或放开驱动器使能。所有安全输出应先在示波器和万用表上确认，再执行有机械风险的动作。

## 12. 必测项目和验收标准

| 类别 | 必测内容 | 通过要求 |
|---|---|---|
| 电源 | 输入、逻辑、CAN、MAX14830、射频电源的电压、纹波、启动和掉电 | 无异常过冲、无明显跌落，满足器件规格 |
| 传感器电源故障 | 逐组短路 `5V_SENSOR` 并验证限流、关断和故障反馈 | 3.3V 逻辑、MCU、CAN 和硬件安全门控持续正常，故障分支可定位 |
| MCU | SWD、BOOT、NRST、主频、IWDG/WWDG、复位原因 | 可稳定下载，故障时能按预期复位并记录 |
| CAN1 | 上位机/BCM 主干收发、保护和终端 | 独立收发，错误计数和超时可观测 |
| CAN2 | 4 个转向电机总线基础通信 | 四个逻辑轴可区分，终端可配置 |
| CAN3 | 两台驱动器 CANopen 总线 | 节点、心跳、PDO/SDO 基础测试可执行 |
| UART | 8 路超声波、4 路 ToF、BMS | 通道映射正确，无明显丢帧，保护/电平兼容 |
| SPI | 三颗 MAX14830 的片选、中断和 FIFO | 可独立读写，IRQ 不串扰，连续数据不丢失 |
| 无线 | nRF52840 独立固件、SWD、主机协议、复位和天线链路 | 低延迟链路、版本兼容、CRC/心跳及已武装模式下失联停车可验证 |
| 安全 | 本地急停、外部监督器、四个驱动轴和四个转向轴的安全路径与反馈 | 任何安全故障均使八轴进入经验证的安全态，不依赖普通软件轮询 |
| 机械接口 | 防水汽车连接器插拔、锁止/防呆、线束密封、外壳和天线空间 | 无干涉、无误插，维修可达 |

验收记录中应保存电源测量值、总线抓包、复位原因、急停时序、无线失联时序和所有异常项的处理结论。

## 16. 交付判断

当电源与安全链路完成硬件审查，三路 CAN、MAX14830、BMS UART 和 nRF52840 的接口资料已足够支撑首件测试，且板厂确认层叠、阻抗、连接器和装配工艺可制造后，VCU PCB 才可进入首版打板。首版目标是验证板级电气和安全基础，不以一次性冻结所有厂家协议为前提，但所有未冻结项必须在生产资料中显式标注。
